Как работать с файлами в командной строке Linux?

JuniorLinux и диагностика
Ещё спрашивают так:
  • Основные команды терминала
  • Как скопировать или удалить папку в терминале?
Коротко

pwd — где я, ls -la — что здесь (со скрытыми и правами), cd — перейти (cd .. — вверх, cd ~ — домой, cd - — назад). mkdir -p — создать каталоги, touch — пустой файл, cp -r — копировать (с каталогами), mv — переместить или переименовать, rm — удалить, rm -r — каталог. cat, less — посмотреть файл, head и tail — начало и конец. Tab дополняет пути, стрелка вверх и Ctrl+R — история команд.

  • rm удаляет безвозвратно, корзины нет; rm -rf с переменной в пути — классическая катастрофа
  • Относительные пути — от текущего каталога, абсолютные — от /
  • man команда или команда --help — справка

А ещё Пробелы в именах — в кавычках: cp "мой файл.txt" backup/

Подробно

Пример сессии:

cd ~/projects
mkdir -p demo/src
cd demo
touch src/app.py
cp src/app.py src/app_backup.py
mv src/app_backup.py /tmp/
ls -la src
tail -n 20 /var/log/syslog

Безопасность: перед rm -r проверить путь через ls; не запускать команды из интернета, не понимая их.

Что хотят услышать

  • Навигация: pwd, ls, cd.
  • Работа с файлами: mkdir, cp, mv, rm.
  • Просмотр: cat, less, head, tail.
  • Осторожность с rm.

Проверьте себя

Один верный вариант. Подумайте, потом откройте ответ.

Показать варианты и ответ
  • ✗cp без -r копирует каталоги целиком
  • ✓pwd, ls, cd — навигация; cp -r, mv, rm — файлы; rm удаляет безвозвратно
  • ✗rm перемещает файл в корзину, откуда его можно восстановить командой trash-restore
  • ✗mv только перемещает, переименовать файл в терминале нельзя
