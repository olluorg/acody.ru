Как в Spring Boot 3 возвращать ошибки REST API в едином формате?

MiddleSpring MVC и RESTSpring BootSpringSpring Boot >=3
Ещё спрашивают так:
  • Что такое ProblemDetail?
  • Как централизованно обрабатывать исключения в REST API?
Коротко

@RestControllerAdvice с @ExceptionHandler централизует обработку, а ответ — ProblemDetail (стандарт RFC 9457, application/problem+json): type, title, status, detail, instance и свои поля.

  • Spring 6 / Boot 3: ProblemDetail и ErrorResponse из коробки
  • spring.mvc.problemdetails.enabled=true — стандартные исключения MVC в этом формате
  • Наружу — понятный код ошибки и correlation id, без стектрейса

А ещё Валидация: MethodArgumentNotValidException → 400 с полями ошибок

Подробно

Централизация. Класс с @RestControllerAdvice содержит методы @ExceptionHandler(OrderNotFoundException.class) и применяется ко всем контроллерам: маппинг исключений на HTTP-ответы в одном месте, без try/catch в каждом методе.

Единый формат — ProblemDetail. RFC 9457 (ранее 7807) описывает тело ошибки: type (URI типа проблемы), title, status, detail, instance и расширения. Spring Framework 6 добавил класс ProblemDetail и интерфейс ErrorResponse; ResponseEntityExceptionHandler можно расширить, чтобы стандартные исключения MVC (неверный JSON, неподдерживаемый метод, ошибки валидации) тоже возвращались в этом формате. В Spring Boot — spring.mvc.problemdetails.enabled=true.

Что отдавать:

  • правильный статус: 400 — неверный запрос, 404 — нет ресурса, 409 — конфликт состояния, 422 — бизнес-валидация, 500 — неожиданная ошибка;
  • машинный код ошибки (type или своё поле code) для клиентов;
  • ошибки полей валидации списком;
  • trace/correlation id для поддержки;
  • никаких стектрейсов и SQL — их в лог.

Пример

@RestControllerAdvice
class ApiErrors {
    @ExceptionHandler(OrderNotFoundException.class)
    ProblemDetail notFound(OrderNotFoundException e) {
        ProblemDetail pd = ProblemDetail.forStatusAndDetail(HttpStatus.NOT_FOUND, e.getMessage());
        pd.setType(URI.create("https://api.shop.ru/errors/order-not-found"));
        pd.setProperty("orderId", e.orderId());
        return pd;
    }
}

  • ProblemDetail и RFC 9457 в Spring 6 / Boot 3.
  • Правильные статусы и что нельзя отдавать наружу.

Частые ошибки

  • Отдавать стектрейс клиенту.
  • Возвращать 200 с полем error.
