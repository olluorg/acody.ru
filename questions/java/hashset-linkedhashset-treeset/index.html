Чем HashSet, LinkedHashSet и TreeSet отличаются?

JuniorКоллекции
Ещё спрашивают так:
  • Какое множество выбрать в Java?
Коротко

HashSet — без порядка, операции O(1); LinkedHashSet — помнит порядок вставки, O(1); TreeSet — отсортирован (красно-чёрное дерево), O(log n) и навигация: first, ceiling, subSet.

  • Уникальность: HashSet и LinkedHashSet — hashCode и equals, TreeSet — compareTo или компаратор
  • HashSet — вариант по умолчанию
  • TreeSet не допускает null (естественный порядок)

А ещё Неизменяемое — Set.of(...), без гарантированного порядка

Подробно

HashSet построен на HashMap: элементы — ключи. Добавление, удаление, contains — O(1) в среднем. Порядок обхода не определён и может меняться после расширения таблицы.

LinkedHashSet — то же плюс двусвязный список по всем элементам: обход в порядке вставки. Немного больше памяти. Удобен, когда нужна уникальность и стабильный порядок (удалить дубли из списка, сохранив порядок: new LinkedHashSet<>(list)).

TreeSet построен на TreeMap (красно-чёрное дерево): элементы отсортированы по естественному порядку или компаратору. Операции O(log n). Даёт навигацию NavigableSet: first, last, floor, ceiling, headSet, tailSet, subSet, descendingSet. Уникальность определяется сравнением, а не equals.

Выбор: просто уникальность — HashSet; плюс порядок вставки — LinkedHashSet; сортировка или запросы «ближайший», «в диапазоне» — TreeSet.
