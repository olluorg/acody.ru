Для чего предназначен record?

JuniorСовременная JavaJava >=16
Ещё спрашивают так:
  • Чем record отличается от обычного класса?
  • Можно ли добавить проверку в конструктор record?
  • Можно ли использовать record как JPA-сущность?
  • Что такое record и когда его использовать?
Коротко

record — компактный неизменяемый носитель данных: поля в заголовке, а конструктор, аксессоры, equals, hashCode и toString создаёт компилятор.

  • Поля final, наследоваться от класса нельзя, но интерфейсы реализовывать можно
  • Проверки — в компактном конструкторе

А ещё Неизменяемы поля, а не объекты по ссылкам: список внутри нужно копировать

Подробно

Record (Java 16) убирает шаблонный код для классов-данных: DTO, ключей составных карт, промежуточных результатов. Объявление record Point(int x, int y) даёт:

  • private final поля x и y;
  • канонический конструктор;
  • аксессоры x() и y() (без префикса get);
  • equals и hashCode по значениям полей;
  • читаемый toString.

Ограничения: record неявно final, не может наследовать класс (но реализует интерфейсы), не может объявлять дополнительные поля экземпляра. Можно добавлять методы, статические поля и конструкторы.

Проверку и нормализацию данных делают в компактном конструкторе — без списка параметров.

Важная тонкость: неизменяемы ссылки, а не объекты. Если поле — список, его стоит копировать в неизменяемый (List.copyOf).

JPA-сущностью record быть не может: Hibernate нужны изменяемые поля и конструктор без аргументов. А вот для DTO и проекций запросов он отлично подходит.

Пример

public record Money(BigDecimal amount, String currency) {
    public Money {                                  // компактный конструктор
        if (amount.signum() < 0) throw new IllegalArgumentException("amount < 0");
        currency = currency.toUpperCase();
    }
}

new Money(new BigDecimal("10"), "rub").equals(new Money(new BigDecimal("10"), "RUB")); // true

Частые ошибки

  • Пытаться добавить сеттеры или унаследовать record от класса.
  • Считать объект полностью неизменяемым при изменяемых полях внутри.
