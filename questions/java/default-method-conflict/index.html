Вопросы / Java / Класс реализует два несвязанных интерфейса, в каждом из которых есть default-метод с одинаковой сигнатурой. Что произойдёт?

Класс реализует два несвязанных интерфейса, в каждом из которых есть default-метод с одинаковой сигнатурой. Что произойдёт?

MiddleООП
Коротко

Ошибка компиляции: класс обязан переопределить метод. Выбрать реализацию можно явно: A.super.method().

  • Правила: метод класса сильнее любого default
  • Более специфичный интерфейс сильнее более общего
  • Абстрактный метод в одном интерфейсе и default в другом — тоже конфликт

А ещё Язык не угадывает намерение — требует явного решения

Подробно

Так решена проблема ромбовидного наследования при добавлении default-методов: язык не угадывает намерение, а требует явного решения. Полезно знать и правила разрешения в других случаях: реализация класса всегда сильнее любого default-метода интерфейса, а более специфичный интерфейс сильнее более общего — если один из интерфейсов наследует другой, конфликта не возникает. Отсюда же принципиальное ограничение default-методов: они не могут переопределять методы класса Object, поэтому объявить в интерфейсе default-реализацию equals или toString нельзя.

Частые ошибки

  • Рассчитывать на порядок в implements.
  • Пытаться объявить default-реализацию equals или hashCode.
