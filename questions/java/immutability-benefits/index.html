Что даёт неизменяемость (immutability) объекта?

JuniorООП
Ещё спрашивают так:
  • Зачем нужны неизменяемые объекты?
  • Как сделать класс неизменяемым?
  • Почему String неизменяемый?
Коротко

Неизменяемый объект потокобезопасен без синхронизации, безопасен как ключ Map / элемент Set и его можно свободно кэшировать и делить.

  • Как сделать: final-класс, private final поля, нет сеттеров, защитные копии изменяемых полей
  • record — быстрый способ, но копии вложенных коллекций всё равно на вас

А ещё Цена — новые объекты при каждом «изменении»

Подробно

У неизменяемого (immutable) объекта наблюдаемое состояние не меняется после создания. Отсюда преимущества:

  • потокобезопасность — состояние нечем испортить гонкой, объект можно передавать между потоками без блокировок;
  • безопасность в хеш-коллекциях — хеш не изменится после добавления в HashMap или HashSet, объект не «потеряется»;
  • кэширование и переиспользование — один экземпляр можно отдавать всем (как String и пул строк);
  • простота рассуждений — объект нельзя изменить «снаружи» по ссылке.

Как сделать класс неизменяемым:

  1. запретить наследование (final класс или приватный конструктор);
  2. все поля private final;
  3. никаких сеттеров и методов, меняющих состояние;
  4. изменяемые поля (списки, даты старого API) копировать при создании и не отдавать наружу как есть — возвращать копию или неизменяемое представление.

Record даёт пункты 1–3 автоматически, но если поле — список, неизменяемость нужно обеспечить самому (List.copyOf). Цена подхода — «изменение» создаёт новый объект, поэтому для частых правок используют изменяемые билдеры (StringBuilder).

Пример

public record Order(long id, List<String> items) {
    public Order {
        items = List.copyOf(items); // защитная неизменяемая копия
    }
}

  • Три выгоды: потокобезопасность, ключи коллекций, кэширование.
  • Как сделать класс неизменяемым, включая защитные копии.
  • Ограничение record с изменяемыми полями — плюс.

Частые ошибки

  • Связывать неизменяемость с хранением в стеке.
  • Думать, что она убирает NPE.
