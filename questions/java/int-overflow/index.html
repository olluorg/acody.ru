Чему равно Integer.MAX_VALUE + 1 и бросит ли это исключение?

JuniorОсновы языка
Коротко

Integer.MIN_VALUE, без исключения: целочисленная арифметика молча заворачивается по модулю 2³². 2147483647 + 1 = −2147483648.

  • Классика: (low + high) / 2 в бинарном поиске — low + (high − low) / 2
  • Защита: Math.addExact, multiplyExact бросают ArithmeticException
  • Считать в long или BigInteger

А ещё Деление на ноль для int бросает ArithmeticException, для double — Infinity

Подробно

Целочисленная арифметика в Java работает по модулю 2^n и молча переполняется — это частый источник багов (например, в (low + high) / 2 при бинарном поиске). Если нужна защита, используют Math.addExact / Math.multiplyExact (бросают ArithmeticException) или считают в long.

Частые ошибки

  • Ждать ArithmeticException от обычного + (его бросает только деление на ноль у целых).
  • Думать, что int сам расширится до long.
