Чем отличаются атрибуты async и defer у тега script?

JuniorБраузер и DOM
Ещё спрашивают так:
  • Где подключать скрипты на странице?
Коротко

Обычный <script> останавливает разбор HTML до загрузки и выполнения. defer — загрузка параллельно, выполнение после разбора HTML, по порядку подключения. async — загрузка параллельно, выполнение сразу по готовности, в произвольном порядке.

  • defer — для скриптов приложения, зависящих от DOM и друг от друга
  • async — для независимых (аналитика, реклама)
  • type="module" по умолчанию ведёт себя как defer

А ещё Скрипты в конце body — старый способ добиться того же

без атрибутаблокирует парсерсразупо порядку
deferпараллельнопосле разбора, до DOMContentLoadedпо порядку
asyncпараллельнокак загрузится, прерывая разборлюбой

Почему это важно. Синхронный скрипт в head задерживает первую отрисовку на время сетевого запроса. defer позволяет браузеру продолжать строить DOM.

Модули (type="module") отложены по умолчанию, поддерживают import; с async выполняются по готовности.

Связанные приёмы: <link rel="preload"> для критичных ресурсов, preconnect к сторонним доменам, разделение бандла на части и ленивая загрузка через import().
