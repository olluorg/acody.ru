Что такое доступность веб-интерфейса и с чего её начинать?

JuniorБраузер и DOM
Ещё спрашивают так:
  • Что такое a11y?
  • Что такое WCAG?
Коротко

Доступность — возможность пользоваться интерфейсом людям с нарушениями зрения, слуха, моторики, когнитивными особенностями, а также всем в неудобных условиях (солнце, одна рука). Стандарт — WCAG (уровень AA — обычная цель). Основы: семантическая разметка, текстовые альтернативы (alt), подписи полей (label), работа с клавиатуры и видимый фокус, достаточный контраст (4.5:1 для текста), не передавать смысл только цветом, масштабирование до 200 % без поломок.

  • Проверка: пройти сценарий только клавиатурой, включить скринридер, Lighthouse и axe
  • Доступность дешевле закладывать сразу, чем чинить потом
  • В ряде стран и для госзаказчиков — требование закона

Подробно

Быстрая проверка формы: у каждого поля есть label; ошибки описаны текстом, а не только красной рамкой; Tab проходит поля по порядку; кнопка отправки — настоящий button.

Показать варианты и ответ

  • ✗Достаточно добавить кнопку «версия для слабовидящих» и расставить ARIA-роли на все блоки страницы
  • ✓Семантика, подписи и alt, клавиатура и видимый фокус, контраст; ориентир — WCAG AA
  • ✗Ошибки формы достаточно показывать красной рамкой, без текста
