Что такое утилитарный CSS (Tailwind) и какие у него плюсы и минусы?

JuniorВёрстка и CSS
Ещё спрашивают так:
  • Почему в Tailwind столько классов в разметке?
Коротко

Tailwind — набор маленьких классов-утилит (flex, p-4, text-lg, md:grid-cols-2), из которых стиль собирается прямо в разметке. Плюсы: не нужно придумывать имена, стили не разрастаются (в сборку попадают только используемые классы), ограниченная шкала отступов и цветов из конфигурации поддерживает единообразие, быстро вносить изменения. Минусы: длинные списки классов, разметка смешана со стилями, нужна дисциплина выносить повторы в компоненты.

  • Повторяющиеся сочетания — в компонент, а не копировать
  • Конфигурация Tailwind = токены дизайн-системы
  • Хорошо сочетается с компонентными фреймворками

Подробно

<button class="rounded-lg bg-indigo-600 px-4 py-2 text-white hover:bg-indigo-500">Купить</button>

Что хотят услышать

  • Идея утилитарных классов.
  • Плюсы: имена, размер CSS, шкалы.
  • Минусы и выделение компонентов.
