Как делить состояние между компонентами в Svelte?

JuniorАрхитектура фронтенда
Ещё спрашивают так:
  • Что такое store в Svelte?
Коротко

Между родителем и ребёнком — props и колбэки (или bind). Для общего состояния нескольких компонентов в Svelte 5 выносят $state в отдельный модуль (.svelte.js) и импортируют его — реактивность работает и вне компонентов. Классический способ — stores: writable, readable, derived с подпиской; в компоненте значение читается через префикс $store с автоматической отпиской. Для данных глубоко по дереву — context (setContext/getContext); в SvelteKit серверное состояние, общее между пользователями, держать в модулях опасно.

  • Store — объект с методом subscribe, легко писать свой
  • $store в шаблоне сам отписывается при уничтожении компонента
  • Данные страниц в SvelteKit — через функции load

Подробно

// cart.svelte.js
export const cart = $state({ items: [] });
// в компоненте
import { cart } from './cart.svelte.js';
cart.items.push(item);
