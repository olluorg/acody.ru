Что фронтенд-разработчику нужно знать про SEO?

JuniorБраузер и DOM
Ещё спрашивают так:
  • Как сделать сайт видимым для поисковиков?
Коротко

Поисковик должен получить содержимое страницы, понять его и оценить качество. Для этого: контент доступен в HTML без обязательного выполнения JS (SSR или статическая генерация для публичных страниц), уникальные title и description, один h1 и иерархия заголовков, семантическая разметка, понятные URL, canonical для дублей, sitemap.xml и robots.txt, быстрая загрузка (Core Web Vitals), адаптивность, alt у изображений, внутренние ссылки обычными a href.

  • SPA без SSR индексируется хуже и медленнее
  • Переходы по кнопкам с onClick поисковик не увидит — нужны ссылки
  • Проверка: Яндекс Вебмастер, Google Search Console

Подробно

Каждой странице — свой адрес и своё содержимое. Фильтры и сортировки, создающие тысячи похожих адресов, закрывают canonical или noindex.

Что хотят услышать

  • Контент в HTML, SSR для публичных страниц.
  • title, description, заголовки, canonical.
  • sitemap, robots, скорость.

Проверьте себя

Один верный вариант. Подумайте, потом откройте ответ.

Показать варианты и ответ
  • ✗Поисковики одинаково хорошо индексируют любые SPA без SSR, поэтому важен лишь контент
  • ✓Контент в HTML без обязательного JS, уникальные title и description, заголовки, canonical, sitemap
  • ✗Переходы между страницами лучше делать кнопками с onClick
  • ✗SEO зависит только от количества ключевых слов на странице
