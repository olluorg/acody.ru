Как работает реактивность во Vue — ref, reactive, computed, watch?

JuniorАрхитектура фронтенда
Ещё спрашивают так:
  • Чем ref отличается от reactive?
Коротко

Vue отслеживает, какие реактивные значения прочитал шаблон или вычисление, и при их изменении сам обновляет только зависимое. ref — обёртка для любого значения (в скрипте .value, в шаблоне без него), reactive — реактивный объект (нельзя переприсвоить целиком и деструктурировать без потери реактивности). computed — производное значение с кэшем, пересчитывается при изменении зависимостей. watch — побочный эффект при изменении (запрос, сохранение). В отличие от React, мутировать реактивное состояние можно — Vue это видит через Proxy.

  • computed без побочных эффектов
  • Деструктуризация reactive теряет реактивность — toRefs
  • watchEffect сам собирает зависимости

Подробно

const items = ref([])
const total = computed(() => items.value.reduce((s, i) => s + i.price, 0))
watch(total, t => localStorage.setItem('total', t))
items.value.push({ price: 100 }) // total пересчитается

Что хотят услышать

  • Отслеживание зависимостей.
  • ref и reactive.
  • computed и watch.
