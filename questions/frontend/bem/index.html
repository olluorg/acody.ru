Что такое БЭМ и зачем методологии именования CSS?

JuniorВёрстка и CSS
Ещё спрашивают так:
  • Как называть CSS-классы?
Коротко

В CSS все классы глобальны, и в большом проекте стили начинают конфликтовать. БЭМ (блок, элемент, модификатор) даёт соглашение: .card — блок, .card__title — элемент блока, .card--featured — модификатор. Классы плоские, специфичность низкая и одинаковая, по имени видно, к чему относится стиль, блок можно переносить. Альтернативы, которые решают ту же проблему инструментами: CSS Modules, CSS-in-JS, утилитарный Tailwind.

  • Не вкладывать селекторы глубоко: .menu ul li a — хрупко
  • Стили блока не зависят от места на странице
  • Методология важна, пока стили глобальные

Подробно

<div class="card card--featured">
  <h3 class="card__title">…</h3>
  <button class="card__button card__button--primary">…</button>
</div>

Что хотят услышать

  • Проблема глобальных классов.
  • Блок, элемент, модификатор.
  • Низкая и одинаковая специфичность.

Показать варианты и ответ
  • ✗БЭМ рекомендует глубоко вкладывать селекторы
  • ✓БЭМ — соглашение блок__элемент--модификатор: плоские классы с низкой специфичностью, без конфликтов глобальных стилей
  • ✗БЭМ — это JavaScript-фреймворк
  • ✗БЭМ нужен, только если используется Tailwind
