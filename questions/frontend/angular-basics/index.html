Как устроено приложение на Angular?

JuniorАрхитектура фронтенда
Ещё спрашивают так:
  • Чем Angular отличается от React?
Коротко

Angular — полноценный фреймворк «всё включено» на TypeScript: компоненты, маршрутизация, формы, HTTP-клиент, тестирование, CLI. Компонент — класс с декоратором @Component, шаблоном и стилями; в шаблоне — привязки: {{ значение }}, [свойство]="выражение", (событие)="обработчик()", двусторонняя [(ngModel)], управляющие блоки @if, @for. Логику и данные выносят в сервисы, которые подключаются через внедрение зависимостей. Реактивность — сигналы (signal, computed) и RxJS.

  • Современный Angular — standalone-компоненты без NgModule
  • Жёсткая структура удобна большим командам и корпоративным проектам
  • ng generate создаёт компоненты и сервисы по шаблону

Подробно

@Component({
  selector: 'app-counter',
  template: `<button (click)="inc()">{{ count() }}</button>`,
})
export class CounterComponent {
  count = signal(0);
  inc() { this.count.update(c => c + 1); }
}

  • Фреймворк «всё включено» на TypeScript.
  • Компонент, шаблон и привязки.
  • Сервисы, DI, сигналы.
