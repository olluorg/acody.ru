Как устроен Redux Toolkit — слайсы, селекторы, middleware?

MiddleReact
Ещё спрашивают так:
  • Что такое action и reducer в Redux?
Коротко

Redux — одно хранилище, состояние меняется только через action (объект «что произошло»), а reducer — чистая функция (state, action) → новое state: без побочных эффектов, поэтому изменения предсказуемы, воспроизводимы и видны в Redux DevTools (история, «путешествие во времени»). Redux Toolkit: createSlice генерирует actions и reducer, внутри можно «мутировать» — Immer создаст копию; configureStore с DevTools. Чтение — useSelector с селектором, запись — useDispatch. Middleware перехватывает actions для асинхронности и логирования (thunk); данные с сервера — RTK Query.

  • Чистота редьюсера — условие предсказуемости и DevTools
  • Мемоизированные селекторы — createSelector
  • Не всё состояние нужно в Redux: формы и локальное — в компонентах

А ещё Для небольших приложений Zustand часто проще

Подробно

const cart = createSlice({
  name: "cart",
  initialState: { items: [] as Item[] },
  reducers: { add(s, a: PayloadAction<Item>) { s.items.push(a.payload); } },
});
