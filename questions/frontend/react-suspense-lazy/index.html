Как разделить код по маршрутам через lazy и Suspense?

MiddleПроизводительность
Ещё спрашивают так:
  • Что делает React.lazy?
  • Зачем вложенные границы Suspense?
Коротко

lazy(() => import("./Page")) превращает компонент в отдельный чанк, который загрузится при первом показе. Пока он грузится, ближайшая &lt;Suspense fallback&gt; показывает запасной интерфейс. Делить код логично по маршрутам и тяжёлым редко нужным частям (редактор, графики). Вложенные границы Suspense дают постепенное появление: каркас страницы сразу, медленные блоки — по мере готовности, каждый со своим скелетоном. Suspense работает и для данных — с библиотеками и фреймворками, которые его поддерживают.

  • Ошибку загрузки чанка ловит граница ошибок
  • Слишком мелкое деление — много запросов
  • Предзагрузка при наведении на ссылку ускоряет переход

А ещё Скелетон похожей формы воспринимается быстрее, чем спиннер

Подробно

const Reports = lazy(() => import("./pages/Reports"));
<Suspense fallback={<PageSkeleton />}>
  <Reports />
</Suspense>

Что хотят услышать

  • lazy и отдельные чанки.
  • Suspense и fallback.
  • Деление по маршрутам и вложенные границы.

Показать варианты и ответ

  • ✓lazy выносит компонент в отдельный чанк, Suspense показывает fallback во время загрузки; делят по маршрутам, вложенные границы дают постепенный показ
  • ✗Suspense ловит ошибки загрузки чанка вместо границы ошибок
  • ✗Чем мельче деление на чанки, тем всегда быстрее
