Что такое разделение кода (code splitting) и ленивая загрузка?

MiddleПроизводительность
Ещё спрашивают так:
  • Как уменьшить размер начального бандла?
  • Что делает dynamic import?
Коротко

Вместо одного большого бандла код делят на части, которые грузятся по необходимости: по маршрутам (страница настроек не нужна на главной), по тяжёлым виджетам (редактор, графики, карта). Механизм — динамический import(), сборщик выделяет модуль в отдельный файл; в React — lazy + Suspense. Общие зависимости выносятся в общий чанк. Важно не раздробить слишком мелко: много мелких запросов тоже медленно.

  • Предзагрузка вероятных следующих маршрутов (prefetch) — по наведению или в простое
  • Анализ бандла: какие библиотеки тяжёлые, есть ли дубли
  • Тяжёлую библиотеку часто можно заменить или импортировать частично

Подробно

button.addEventListener('click', async () => {
  const { openEditor } = await import('./editor.js');
  openEditor();
});

Что хотят услышать

  • Деление по маршрутам и тяжёлым компонентам.
  • Динамический import, lazy и Suspense.
  • Баланс числа чанков, prefetch.
