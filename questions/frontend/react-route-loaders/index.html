Как загружать данные до показа страницы в React Router?

MiddleReact
Ещё спрашивают так:
  • Что такое loader в React Router?
Коротко

loader маршрута — функция, которую роутер вызывает при переходе, параллельно для всех вложенных маршрутов, до рендера страницы; компонент читает результат через useLoaderData(). Так нет «водопада» запросов из вложенных эффектов и мигания пустых состояний. action обрабатывает отправку форм маршрута, после чего loaders перезапрашивают данные. Ошибки loader попадают в errorElement маршрута. С кэшем данных хорошо сочетать TanStack Query: loader заполняет кэш, компонент читает из него.

  • useNavigation().state — индикатор загрузки при переходе
  • redirect() из loader — для авторизации
  • Медленные данные можно отдать позже через defer и Await

А ещё Тот же подход — загрузка на уровне маршрута — в Next.js и Remix

Подробно

{ path: "orders/:id", element: <Order />, errorElement: <OrderError />,
  loader: ({ params }) => api.getOrder(params.id!) }
function Order() { const order = useLoaderData() as Order; ... }

Что хотят услышать

  • loader до рендера, параллельно.
  • useLoaderData, action, errorElement.
  • Устранение водопада запросов.

  • ✗loader заменяет сервер и хранит данные
  • ✗Вложенные loaders выполняются строго последовательно, от родителя к ребёнку
  • ✓loader грузит данные при переходе до рендера; компонент читает их через useLoaderData
