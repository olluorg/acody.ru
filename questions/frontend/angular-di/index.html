Как работает внедрение зависимостей в Angular?

JuniorАрхитектура фронтенда
Ещё спрашивают так:
  • Что делает @Injectable?
  • Что такое providedIn root?
Коротко

Сервис — класс с @Injectable; Angular сам создаёт его экземпляр и передаёт компонентам и другим сервисам, которые его запросили (через конструктор или функцию inject()). providedIn: 'root' — один экземпляр на всё приложение (синглтон); провайдер на уровне компонента — свой экземпляр для компонента и его детей. DI упрощает тестирование (подмена сервиса фейком) и разделяет ответственность: компонент показывает, сервис получает и хранит данные.

  • Иерархия инжекторов повторяет дерево компонентов
  • Токены (InjectionToken) — для конфигурации и не-классов
  • HttpClient тоже приходит через DI

Подробно

@Injectable({ providedIn: 'root' })
export class OrdersService {
  private http = inject(HttpClient);
  list() { return this.http.get<Order[]>('/api/orders'); }
}

Что хотят услышать

  • Injectable и автоматическое создание.
  • Синглтон root и провайдеры компонентов.
  • Польза для тестов.
