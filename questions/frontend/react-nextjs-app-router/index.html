Как устроен App Router в Next.js — маршруты, раскладки, загрузка данных?

MiddleReact
Ещё спрашивают так:
  • Что такое layout.tsx и page.tsx?
Коротко

Маршруты — папки в app/: app/orders/[id]/page.tsx → /orders/123. layout.tsx оборачивает вложенные страницы и не перемонтируется при переходах между ними; loading.tsx — Suspense-заглушка, error.tsx — граница ошибок, not-found.tsx — 404. Компоненты по умолчанию серверные: данные загружают прямо в компоненте через async/await (fetch, запрос к базе), без useEffect. Метаданные страницы — export metadata или generateMetadata.

  • Динамические параметры — params в props страницы
  • Группы (folder) и параллельные маршруты для сложных раскладок
  • Route handlers (route.ts) — свои API-эндпоинты

А ещё Клиентские компоненты нужны только там, где интерактивность

Подробно

// app/orders/[id]/page.tsx
export default async function OrderPage({ params }: { params: Promise<{ id: string }> }) {
  const { id } = await params;
  const order = await db.order.find(id);
  if (!order) notFound();
  return <OrderView order={order} />;
}

Что хотят услышать

  • Маршруты из файлов, page и layout.
  • loading, error, not-found.
  • Серверная загрузка данных async/await.
