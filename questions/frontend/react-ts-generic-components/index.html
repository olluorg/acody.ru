Как написать дженерик-компонент и типизировать контекст с проверкой провайдера?

MiddleTypeScript
Ещё спрашивают так:
  • Как сделать типизированный компонент списка или таблицы?
Коротко

Дженерик-компонент получает параметр типа из данных: function List<T>({ items, render }: { items: T[]; render: (item: T) => ReactNode }) — внутри render тип элемента известен без приведений. Ограничение — T extends { id: string }, если нужен ключ. Контекст создают с null по умолчанию и пишут хук-обёртку, который бросает понятную ошибку без провайдера и возвращает не-null тип: потребителям не нужны проверки на null.

  • В .tsx запись <T,> помогает отличить дженерик от тега у стрелочных функций
  • Тип строки таблицы выводится из переданных данных
  • Ошибка «useX must be used within XProvider» экономит часы отладки

А ещё as any внутри компонента сводит пользу дженерика на нет

Подробно

const AuthCtx = createContext<Auth | null>(null);
export function useAuth() {
  const ctx = useContext(AuthCtx);
  if (!ctx) throw new Error("useAuth: нет AuthProvider выше по дереву");
  return ctx;   // тип Auth
}
function Select<T extends { id: string }>({ options, value, onChange, label }: SelectProps<T>) { ... }

  • Параметр типа из данных.
  • Ограничения extends.
  • Контекст с null и проверяющий хук.
