Чем Svelte отличается от React и Vue?

JuniorАрхитектура фронтенда
Ещё спрашивают так:
  • Почему Svelte называют компилятором?
  • Что такое руны в Svelte?
Коротко

Svelte — компилятор: компоненты (.svelte) превращаются при сборке в небольшой JS, который напрямую обновляет DOM, без виртуального DOM и тяжёлой библиотеки в рантайме — меньше бандл и быстрый старт. Реактивность в Svelte 5 — руны: $state (состояние), $derived (производное), $effect (побочный эффект), $props (входные данные). Шаблон: {#if}, {#each}, on:click/onclick, bind:value. Для приложений с маршрутизацией и SSR — SvelteKit.

  • Меньше шаблонного кода, чем в React
  • Экосистема и рынок вакансий меньше, чем у React и Vue
  • Стили в компоненте изолированы по умолчанию

Подробно

<script>
  let count = $state(0);
  let double = $derived(count * 2);
</script>
<button onclick={() => count++}>{count} × 2 = {double}</button>

Что хотят услышать

  • Компилятор без виртуального DOM.
  • Руны $state, $derived, $effect.
  • SvelteKit.
