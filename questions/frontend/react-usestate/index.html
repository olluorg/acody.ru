Как работает useState?

JuniorReact
Ещё спрашивают так:
  • Почему состояние сохраняется между рендерами?
Коротко

const [value, setValue] = useState(initial) — React хранит значение вне функции компонента, привязав его к позиции хука; при следующих рендерах возвращает текущее. setValue планирует перерисовку; если новое значение равно старому (Object.is) — рендер пропускается. Начальное значение используется только один раз; дорогое вычисление передают функцией: useState(() => parse(data)). Объекты и массивы обновляют неизменяемо — создают новые.

  • Несколько независимых значений — несколько useState
  • Связанные поля со сложной логикой — useReducer
  • Обновления в обработчиках событий группируются в один рендер

А ещё Мутация объекта и setState с той же ссылкой — React не увидит изменения

Подробно

const [items, setItems] = useState<string[]>([]);
const add = (s: string) => setItems(prev => [...prev, s]);
const [config] = useState(() => JSON.parse(localStorage.config ?? "{}"));

Что хотят услышать

  • Хранение между рендерами.
  • setState планирует рендер, сравнение Object.is.
  • Ленивая инициализация и неизменяемость.
