Что такое npm-скрипты и npx?

JuniorВыкатка и эксплуатация
Ещё спрашивают так:
  • Как запустить локально установленный пакет?
Коротко

Раздел scripts в package.json — именованные команды проекта: npm run dev, npm run build, npm test. В скриптах доступны бинарники из node_modules/.bin без указания пути — поэтому инструменты ставят локально в devDependencies, а не глобально: у всех одинаковые версии. npx запускает бинарник пакета (локальный или скачанный разово).

  • dependencies — нужны в работе, devDependencies — только для разработки и сборки
  • pre/post-скрипты: prebuild выполнится перед build
  • Единые команды упрощают CI и онбординг

Подробно

"scripts": {
  "dev": "vite",
  "build": "tsc --noEmit && vite build",
  "test": "vitest run"
}

Что хотят услышать

  • scripts и npm run.
  • Локальные инструменты и node_modules/.bin.
  • dependencies против devDependencies.
