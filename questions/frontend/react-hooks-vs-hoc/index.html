Почему пользовательские хуки вытеснили HOC и render props?

MiddleReact
Ещё спрашивают так:
  • Что такое HOC в React?
  • Что такое render props?
Коротко

HOC — функция, которая принимает компонент и возвращает обёрнутый с дополнительными props (withUser(Profile)). Render props — компонент вызывает функцию-проп для отрисовки (<Mouse render={pos => ...}/>). Оба приёма делили логику, но давали «ад обёрток» в дереве, конфликты имён props и неявные зависимости. Пользовательский хук делит ту же логику без лишних компонентов: const user = useUser() — явно, типизируется просто, комбинируется.

  • HOC ещё встречается в старом коде и некоторых библиотеках
  • Хук делит логику, а не состояние: у каждого вызова своё
  • Render props остаются уместны, когда нужно отдать управление разметкой

А ещё Хуки нельзя вызывать условно — правила хуков

Подробно

// HOC
const ProfileWithUser = withUser(Profile);
// хук
function Profile() {
  const user = useUser();
  return <h1>{user.name}</h1>;
}
