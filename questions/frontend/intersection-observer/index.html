Какие браузерные API полезны фронтенд-разработчику — IntersectionObserver, ResizeObserver, Storage, History?

JuniorБраузер и DOM
Ещё спрашивают так:
  • Как сделать бесконечную прокрутку?
  • Как узнать, что элемент появился на экране?
Коротко

IntersectionObserver — сообщает, когда элемент входит в видимую область: ленивая загрузка, бесконечная прокрутка, аналитика просмотров — без дорогих обработчиков scroll. ResizeObserver — изменение размеров элемента. localStorage/sessionStorage — небольшие данные в браузере (строки, синхронно), IndexedDB — большие и структурированные. History API (pushState, popstate) — смена URL без перезагрузки, основа маршрутизации SPA. Ещё: Clipboard, Notifications, Geolocation (с разрешения пользователя), BroadcastChannel между вкладками.

  • Обработчик scroll на каждый кадр — частая причина тормозов
  • В localStorage не хранят токены — доступны любому скрипту при XSS
  • Проверять поддержку API в целевых браузерах

Подробно

const io = new IntersectionObserver(entries => {
  if (entries[0].isIntersecting) loadMore();
});
io.observe(document.querySelector('#sentinel'));

  • ✗localStorage — безопасное место для токенов доступа
  • ✗History API перезагружает страницу при pushState
