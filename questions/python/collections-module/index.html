Когда использовать defaultdict, Counter, deque и OrderedDict?

MiddleКоллекции
Ещё спрашивают так:
  • Что есть в модуле collections?
Коротко

defaultdict(list) — значение по умолчанию для нового ключа (группировка без проверок). Counter — подсчёт: most_common, сложение и вычитание счётчиков. deque — двусторонняя очередь с O(1) по краям и maxlen (скользящее окно). OrderedDict — move_to_end и popitem(last=False), равенство с учётом порядка.

  • list.pop(0) — O(n), deque.popleft() — O(1)
  • Обычный dict хранит порядок вставки с 3.7 — OrderedDict нужен редко
  • defaultdict создаёт ключ даже при чтении d[k] — неожиданно растёт

А ещё ChainMap — несколько словарей как один (настройки по слоям)

Подробно

defaultdict вызывает фабрику при обращении к отсутствующему ключу и кладёт результат в словарь. Удобно для группировки и подсчёта, но if d[key]: тоже создаст пустую запись — для проверки использовать key in d или get.

Counter — словарь «элемент → количество»: Counter("abracadabra"), most_common(n), арифметика c1 + c2, c1 - c2 (отрицательные отбрасываются), total() (3.10).

deque — кольцевая структура из блоков: append, appendleft, pop, popleft за O(1), rotate. Индексация в середину — O(n). С maxlen — ограниченный буфер. Потокобезопасна для append и popleft — часто используется как простая очередь.

OrderedDict после 3.7 нужен для move_to_end (LRU-кэш вручную), popitem(last=False) и сравнения с учётом порядка.

Пример

from collections import defaultdict, Counter, deque

by_city = defaultdict(list)
for u in users: by_city[u.city].append(u)

Counter(words).most_common(3)

last_5 = deque(maxlen=5)
for x in stream: last_5.append(x)     # старые вытесняются сами

Показать варианты и ответ
  • ✓defaultdict — значение для новых ключей, Counter — подсчёт, deque — O(1) с краёв
  • ✗OrderedDict обязателен, чтобы dict сохранял порядок вставки, а deque.popleft() работает за O(n), как list.pop(0)
  • ✗Counter умеет только увеличивать счётчики: складывать и вычитать два Counter нельзя
  • ✗defaultdict при обращении к новому ключу бросает KeyError так же, как обычный dict
