Чем массив отличается от среза в Go?

JuniorСрезы, мапы и строки
Коротко

Массив [5]int — значение фиксированного размера, размер — часть типа ([3]int и [4]int — разные типы); присваивание и передача копируют все элементы. Срез []int — дескриптор над массивом с переменной длиной; копирование дешёвое, данные общие.

  • На практике почти всегда используют срезы
  • Массивы — для фиксированных данных: ключи мапы ([16]byte для хеша), буферы на стеке
  • Массивы можно сравнивать через ==, срезы — нет (только slices.Equal)

А ещё Литерал [...]int{1, 2, 3} — массив, []int{1, 2, 3} — срез

Попробуйте сами

Срезы Go: len, cap, append и общий массив

Подробно

a := [3]int{1, 2, 3}
b := a          // копия
b[0] = 100      // a[0] по-прежнему 1

s := []int{1, 2, 3}
t := s          // тот же массив
t[0] = 100      // s[0] тоже 100

Почему массивы редко нужны. Размер известен на этапе компиляции и входит в тип — функцию для [3]int нельзя вызвать с [4]int. Срезы универсальнее.

Где массивы полезны: сравнимость и хешируемость — массив можно сделать ключом мапы; хеши sha256.Sum256 возвращают [32]byte; небольшие буферы, которые компилятор может разместить на стеке.

  • Размер как часть типа.
  • Копирование против общего массива.
  • Где массивы применяют.
