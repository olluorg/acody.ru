Как выложить статический сайт и подключить к нему свой домен?

JuniorСети
Ещё спрашивают так:
  • Как подключить домен к GitHub Pages?
  • Чем статический хостинг отличается от сервера?
Коротко

Статический сайт — готовые HTML, CSS, JS и картинки, которые отдаются как файлы. Его кладут на статический хостинг (GitHub Pages, облачное объектное хранилище, Netlify и аналоги) — дёшево или бесплатно, быстро, без сервера. Домен покупают у регистратора, в его DNS добавляют запись: для поддомена — CNAME на адрес хостинга, для корневого домена — A-записи на IP хостинга (или ALIAS). Хостинг выпускает сертификат HTTPS (часто Let's Encrypt), когда видит, что домен указывает на него.

  • Если нужен код на сервере (база, авторизация) — статики мало: платформа приложений или свой сервер
  • Сборка сайта (генератор, фреймворк) — в CI, на хостинг — готовые файлы
  • После смены DNS сертификат выпускается не сразу — подождать и проверить

А ещё Корневой домен CNAME-записью указать нельзя — для него A или ALIAS

Подробно

Шаги для поддомена docs.example.ru:

  1. Собрать сайт, выложить на хостинг.
  2. В настройках хостинга указать свой домен.
  3. У регистратора: CNAME docs → адрес хостинга.
  4. Дождаться обновления DNS (dig docs.example.ru).
  5. Включить HTTPS и принудительный редирект с http.

Выбор хостинга: статика — для лендингов, документации, блогов; платформа (PaaS) — для небольших приложений с бэкендом; свой сервер — когда нужен полный контроль.

Что хотят услышать

  • Что такое статический хостинг.
  • Записи DNS: CNAME для поддомена, A для корня.
  • HTTPS-сертификат.
  • Когда статики недостаточно.
