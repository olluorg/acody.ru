Как описать инструмент для модели и обработать цикл «вызов — результат — ответ»?

JuniorИнструменты и агенты
Ещё спрашивают так:
  • Как подключить функцию к LLM?
  • Как выглядит описание инструмента?
Коротко

Инструмент описывают именем, описанием (когда его вызывать) и JSON-схемой параметров. Цикл: отправить запрос с описаниями инструментов → модель вернула запрос на вызов с аргументами → код приложения проверяет аргументы и выполняет функцию → результат отправляют модели отдельным сообщением с идентификатором вызова → модель формирует ответ или вызывает следующий инструмент. Цикл ограничивают максимумом шагов.

  • Описание инструмента — это промпт: от него зависит, вызовет ли модель нужный
  • Аргументы проверяют в коде — модель может передать неверный тип или чужой идентификатор
  • Ошибку инструмента возвращают модели понятным текстом, а не падением

А ещё Модель может вызвать несколько инструментов сразу — их выполняют и возвращают все результаты

Подробно

Описание:

{"name": "get_order_status",
 "description": "Статус заказа клиента по номеру. Вызывай, когда спрашивают, где заказ.",
 "parameters": {"type": "object",
   "properties": {"order_id": {"type": "string"}},
   "required": ["order_id"]}}

Цикл (схематично):

for _ in range(MAX_STEPS):
    resp = llm(messages, tools)
    if not resp.tool_calls:
        return resp.text
    for call in resp.tool_calls:
        result = run_tool(call.name, call.args, user)
        messages.append(tool_result(call.id, result))

  • Цикл с выполнением в коде приложения.

  • Лимит шагов.

  • ✗При ошибке инструмента нужно завершить диалог исключением
