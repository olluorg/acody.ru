Какие бывают задачи машинного обучения — обучение с учителем, без учителя, с подкреплением?

JuniorОсновы машинного обучения
Ещё спрашивают так:
  • Чем классификация отличается от регрессии?
  • Что такое self-supervised learning?
Коротко

С учителем — есть правильные ответы (метки): классификация (предсказать класс — спам/не спам) и регрессия (предсказать число — цену). Без учителя — меток нет, ищем структуру: кластеризация, понижение размерности, поиск аномалий. С подкреплением — агент учится действиям по награде.

  • Self-supervised — метки берутся из самих данных: так предобучают LLM (предсказать следующее слово)
  • Полуавтоматический вариант — semi-supervised: немного меток и много неразмеченных данных
  • Выбор задачи определяет метрику и модель

А ещё Ранжирование и рекомендации — отдельный класс задач со своими метриками (NDCG, MAP)

Подробно

Обучение с учителем (supervised). У каждого примера есть признаки и целевая переменная. Модель учится отображению «признаки → ответ».

  • Классификация — ответ из конечного набора: отток клиента, тип документа, мошенническая транзакция. Метрики: precision, recall, F1, ROC-AUC.
  • Регрессия — ответ — число: цена квартиры, время доставки, спрос. Метрики: MAE, RMSE, MAPE.

Обучение без учителя (unsupervised). Меток нет:

  • кластеризация — сегменты клиентов, группировка документов;
  • понижение размерности — PCA, визуализация, сжатие признаков;
  • поиск аномалий — необычные транзакции, сбои оборудования.

Self-supervised — разметка берётся из данных автоматически: предсказать следующее слово, закрытое слово или фрагмент картинки. Так обучают языковые модели и модели эмбеддингов на огромных объёмах текста без ручной разметки.

С подкреплением (reinforcement learning) — агент совершает действия в среде и получает награду. Классика — игры и робототехника; в LLM — этап RLHF, где награду даёт модель предпочтений людей.

Что хотят услышать

  • Классификация против регрессии с примерами.
  • Что такое self-supervised и при чём тут LLM.
