Участие в найме — собеседование, задача, отзыв и калибровка

Как проводить техническое собеседование по критериям, выбирать задачу, писать отзыв о кандидате и калибровать оценки интервьюеров.

Собеседование — проверка, а не беседа

Качество найма определяет команду через год, и senior часто становится интервьюером. Хорошее техническое собеседование — структурированное:

  • заранее определены критерии и уровни для роли;
  • задачи одинаковые для всех кандидатов на позицию;
  • вопросы близки к реальной работе;
  • письменный отзыв по критериям сразу после встречи;
  • решение — на основе фактов, а не «понравился».

Проверяют рассуждение и компромиссы, а не знание редких фактов. Лучшие вопросы — углубляющие: «почему так?», «что будет при десятикратной нагрузке?», «а если сервис B недоступен?». Уважительный опыт кандидата — часть работы: он потом рассказывает о компании.

Задача для собеседования

Задача проверяет то, что нужно для роли. Для бэкенда — проектирование API и данных, работа с кодом, отладка; не загадки.

Хорошая задача:

  • масштабируется — базовая часть решается за 15–20 минут, дальше идут усложнения для сильных кандидатов;
  • одинакова для всех кандидатов на позицию;
  • опробована на коллегах;
  • имеет критерии оценки и типичные ответы по уровням;
  • имеет продуманные заранее подсказки.

Такая задача даёт разницу между junior, middle и senior на одном условии. Близость к реальной работе важнее «интересности». Если задача утекла в интернет — её меняют, а не запрещают готовиться.

Отзыв о кандидате

Пишут сразу после встречи, по заданным критериям. Для каждого — балл и факты из ответов:

Проектирование данных — 3 из 4. Предложил индекс на (user_id, created_at), объяснил порядок колонок через запрос ленты. Про блокировки при обновлении счётчика не вспомнил даже с подсказкой. Итог: middle, уверенность средняя. На следующем этапе проверить конкурентный доступ к данным.

Наблюдения отделяют от выводов. Подсказки фиксируют: решил сам или с помощью. О том, что к роли не относится — возраст, манера одеваться, — не пишут. «Хороший парень» и «не зашёл» — не отзыв. Отзывы коллег читают только после того, как написали свой, чтобы не подстраиваться. Хороший отзыв позволяет другому человеку понять решение без вас.

Калибровка

Разные интервьюеры по-разному строги, и без договорённостей судьба кандидата зависит от того, к кому он попал. Калибровка:

  • общая шкала с описанием уровней и примерами ответов на каждый балл;
  • парные собеседования — новичок вместе с опытным интервьюером;
  • встреча по решению, где спорные случаи обсуждают по фактам из отзывов, а не по «мне показалось»;
  • сравнение решений с результатами — как работают нанятые.

Новый интервьюер сначала наблюдает, затем проводит под присмотром. Если кто-то всегда ставит выше или ниже остальных — это повод обсудить. Шкалу и задачи пересматривают по итогам найма.

Что запомнить

  • Критерии и задачи — заранее и одинаковые для всех.
  • Задача масштабируется от базовой части к усложнениям.
  • Отзыв — сразу, по критериям, с фактами.
  • Калибровка делает планку одинаковой у всех интервьюеров.
