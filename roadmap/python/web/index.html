Вопросы с собеседований

  • Как найти и исправить проблему N+1 запросов в Django ORM? Middle

    N+1 — один запрос за списком и по запросу на каждый элемент при обращении к связанному объекту в цикле. select_related — JOIN в одном запросе для ForeignKey и OneToOne…

  • Как устроено внедрение зависимостей в FastAPI? Middle

    Depends(func) — FastAPI вызывает func перед обработчиком и передаёт результат в параметр. Зависимости образуют граф, результат кэшируется в пределах запроса, зависимость с yield…

  • Чем WSGI отличается от ASGI? Middle

    WSGI — синхронный интерфейс между веб-сервером и приложением: один запрос занимает один поток или процесс до ответа (Flask, Django). ASGI — асинхронный: приложение — корутина…

  • Как написать простой HTTP API на FastAPI? Junior

    Создать приложение app = FastAPI(), объявить обработчики декораторами @app.get, @app.post и др. Параметр из пути (/items/{item_id}) становится аргументом функции, остальные…

  • Как правильно делать HTTP-запросы из Python — requests и httpx? Junior

    requests — синхронная библиотека, httpx — похожий интерфейс плюс асинхронный клиент и HTTP/2. Обязательные привычки: всегда задавать timeout (по умолчанию requests ждёт…

  • Как работать с JSON в Python и что делать с датами и своими объектами? Junior

    json.dumps(obj) превращает объект в строку, json.loads(s) — строку в объект; dump/load — то же для файлов. Поддерживаются только dict, list, str, int, float, bool, None; кортеж…

  • Как проверять входные данные с помощью Pydantic? Junior

    Pydantic проверяет и преобразует данные во время выполнения по аннотациям класса-наследника BaseModel: строку «42» превратит в int, а «abc» для int отклонит с понятной ошибкой…
