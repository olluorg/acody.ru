Конкурентность и asyncio

Основа с Junior

GIL, потоки и процессы, asyncio, event loop, отмена и блокирующие вызовы.

Что важно знать

  • GIL: один поток выполняет байткод в момент времени; потоки помогают при ожидании ввода-вывода, процессы — при вычислениях.
  • asyncio: корутины, event loop, TaskGroup, asyncio.timeout.
  • Блокирующий вызов в корутине останавливает всё — to_thread или асинхронные клиенты.
  • Free-threaded сборка Python 3.13+ без GIL — экспериментальная.

Критерии освоения

Junior ≈ 6 ч

  • Объясняет GIL и разницу threading, multiprocessing и asyncio

Практика. Сравнить время загрузки 50 страниц последовательно, в потоках и в asyncio.

Middle ≈ 10 ч

  • Пишет асинхронный код с TaskGroup, таймаутами и отменой
  • Выносит блокирующие вызовы из event loop
  • Защищает общее состояние в потоках, несмотря на GIL

Практика. Сделать асинхронный сборщик данных из нескольких API с ограничением параллельности, таймаутами и отменой.

Senior ≈ 6 ч

  • Выбирает модель конкурентности под нагрузку сервиса и объясняет влияние free-threaded Python

Практика. Найти и устранить блокировку event loop в асинхронном сервисе под нагрузкой по профилю.

Вопросы с собеседований

  • Как работают async и await? Junior

    async def создаёт корутину, await — точка, где она отдаёт управление циклу событий, пока ждёт.

  • Что будет, если внутри async-функции вызвать блокирующий код? Middle

    Встанет весь event loop: блокирующий вызов (time.sleep, requests.get, синхронный драйвер БД, тяжёлое вычисление) не отдаёт управление, и все остальные задачи ждут. Решение …

  • Что меняет сборка Python без GIL (free-threaded)? Senior

    Отдельная сборка CPython (python3.13t) без GIL: потоки выполняют Python-код по-настоящему параллельно на разных ядрах. В 3.13 — экспериментальная, в 3.14 — официально…

  • Что такое GIL? Junior

    GIL — блокировка в CPython: байткод Python в один момент выполняет только один поток.

  • Как в asyncio работают отмена задач и таймауты? Middle

    task.cancel() бросает CancelledError внутрь корутины в точке ближайшего await. Таймаут — asyncio.timeout() (3.11) или wait_for: по истечении задача отменяется, наружу …

  • Чем отличаются threading, multiprocessing и asyncio? Junior

    Потоки и asyncio — для ожидания ввода-вывода, процессы — для вычислений на нескольких ядрах.
