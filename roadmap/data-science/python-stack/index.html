Python для данных

Основа

NumPy, pandas, визуализация и разведочный анализ данных.

Рабочий инструмент data scientist — Python: NumPy для вычислений, pandas для таблиц, matplotlib и seaborn для графиков, scikit-learn для моделей, Jupyter для исследования. Уверенный pandas экономит часы на каждой задаче, а разведочный анализ определяет, получится ли модель вообще.

Код исследования со временем должен становиться кодом продакшена — поэтому важны и навыки инженера: функции, модули, тесты, Git.

Темы этапа

  • NumPy и pandas Основа

    Массивы и векторизация, таблицы, группировки, объединения, работа со временем.

  • Разведочный анализ и визуализация Основа

    Качество данных, распределения, связи, выбросы и графики, которые помогают принять решение.
