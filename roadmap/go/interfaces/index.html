    Интерфейсы

    Основа с Junior

    Неявная реализация, пустой интерфейс, type switch, nil-интерфейс.

    Что важно знатьКритерии освоенияПроверка знанийВопросы

    Что важно знать

    • Тип реализует интерфейс, если имеет его методы — без объявления.
    • Маленькие интерфейсы (io.Reader) — идиома Go.
    • Интерфейс — пара (тип, значение); nil-указатель внутри не nil.

    Критерии освоения

    Junior ≈ 6 ч

    • Объявляет маленькие интерфейсы и реализует их неявно

    Практика. Сделать хранилище с интерфейсом и двумя реализациями — в памяти и в файле.

    Middle ≈ 4 ч

    • Объясняет, почему интерфейс с nil-указателем не равен nil
    • Применяет принцип «принимай интерфейсы, возвращай структуры»

    Практика. Воспроизвести ловушку nil-интерфейса при возврате ошибки и исправить.

    Вопросы с собеседований

    Смотреть все
    Что такое any, type assertion и type switch?Junior

    any (= interface{}) — интерфейс без методов, ему удовлетворяет любой тип. Достать конкретный тип — type assertion v, ok := x.(string) (без ok при несовпадении — panic) или type switch по нескольким типам.

    Полный разбор
    Как устроены дженерики в Go и когда их использовать?Middle

    С Go 1.18 функции и типы принимают параметры типов с ограничениями — интерфейсами, которые могут перечислять допустимые типы: func Max[T cmp.Ordered](a, b T) T. Применение — контейнеры и алгоритмы над разными типами (пакеты slices, maps). Для поведения…

    Полный разбор
    Как работают интерфейсы в Go и что значит неявная реализация?Junior

    Тип удовлетворяет интерфейсу автоматически, если у него есть все методы интерфейса — без слова implements. Поэтому интерфейсы объявляют у потребителя и делают маленькими (io.Reader — один метод). «Принимай интерфейсы, возвращай структуры».

    Полный разбор
    Почему интерфейс с nil-указателем внутри не равен nil?Middle

    Интерфейсное значение — пара (тип, значение). Оно равно nil, только когда обе части nil. Если положить в интерфейс nil-указатель конкретного типа, тип уже заполнен — интерфейс не nil, и err != nil срабатывает.

    Полный разбор
    Как в Go обходятся без наследования — что такое встраивание (embedding)?Junior

    Наследования нет. Встраивание — поле без имени: методы и поля встроенного типа продвигаются во внешний и вызываются напрямую. Это композиция, а не наследование: нет переопределения с полиморфизмом — встроенный тип не знает о внешнем.

    Полный разбор
    Когда метод должен иметь получатель-указатель, а когда — значение?Junior

    Указатель func (s Svc) — если метод меняет получателя, структура большая или содержит то, что нельзя копировать (sync.Mutex). Значение func (p Point) — для маленьких неизменяемых типов. Получатели одного типа делают единообразными.
