Сервисы на Go

Основа с Junior

net/http, маршрутизация, middleware, работа с базой и graceful shutdown.

Что важно знать

  • С Go 1.22 стандартный http.ServeMux умеет методы и параметры пути.
  • Middleware — функции-обёртки над http.Handler.
  • database/sql или pgx, пул соединений.
  • Graceful shutdown: server.Shutdown(ctx) по сигналу.

Критерии освоения

Junior ≈ 10 ч

  • Делает HTTP API на net/http с маршрутизацией и JSON

Практика. Сделать API заказов на стандартной библиотеке с тестами через httptest.

Middle ≈ 8 ч

  • Пишет middleware для логирования, авторизации и восстановления после panic
  • Работает с PostgreSQL через pgx и делает graceful shutdown

Практика. Добавить middleware, работу с PostgreSQL через pgx, миграции и корректную остановку по SIGTERM.

Вопросы с собеседований

  • Зачем нужен context.Context? Junior

    Context переносит отмену, дедлайн и значения запроса через цепочку вызовов и горутин. Создают от входящего запроса, передают первым аргументом во все функции с вводом-выводом…

  • Как пишут тесты в Go — табличные тесты, моки, бенчмарки? Junior

    Тесты — функции TestXxx(t testing.T) в файлах _test.go, запуск go test ./.... Идиома — табличные тесты: срез случаев и t.Run для каждого. Зависимости подменяют через маленькие…
