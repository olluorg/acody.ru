Микросервисы на Spring

Основа с Middle

Resilience4j, Spring Cloud — конфигурация, discovery, gateway, трассировка.

Что важно знать

  • Resilience4j: таймаут, повтор, circuit breaker, bulkhead и порядок аспектов.
  • Micrometer Tracing + OpenTelemetry для трассировки.
  • В Kubernetes часть Spring Cloud (discovery, config) заменяют средства платформы.

Критерии освоения

Middle ≈ 6 ч

  • Добавляет таймауты, повторы и circuit breaker через Resilience4j
  • Подключает трассировку Micrometer Tracing и метрики

Практика. Обернуть вызов внешнего сервиса в Resilience4j с circuit breaker и проверить поведение в тесте с медленной заглушкой.

Senior ≈ 6 ч

  • Выбирает компоненты Spring Cloud против средств платформы (Kubernetes, service mesh) и обосновывает

Практика. Сравнить для своего проекта Spring Cloud Gateway и ingress-контроллер Kubernetes и описать выбор.

  • Зачем нужен service discovery в системе из многих сервисов? Junior

    Сервисы обращаются друг к другу по логическому имени, а не по жёстким адресам, которые меняются при каждом развёртывании и масштабировании.
