Сообщения, роли и параметры

Основа с Junior

Как устроен запрос к чат-модели, системный промпт, история диалога и расход токенов.

Что важно знать

  • Системный промпт задаёт роль, правила и формат; пользовательские сообщения — данные и вопросы.
  • История: длинный диалог дорожает с каждым сообщением — обрезают старое, сжимают в резюме, используют кэширование префикса.
  • Параметры: temperature, max_tokens (лимит ответа), stop-последовательности.
  • Ответ содержит причину остановки: закончил, упёрся в лимит токенов, вызвал инструмент — обрабатывать каждую.
  • Ошибки: 429 (превышен лимит запросов) и 5xx — повтор с экспоненциальной паузой; таймауты обязательны.
  • Ключи API — только на сервере, никогда во фронтенде.
  • Абстракция над провайдерами (свой тонкий слой или LiteLLM) упрощает смену модели.

Критерии освоения

Junior ≈ 6 ч

  • Отправляет запрос к API модели с системным промптом и историей диалога
  • Обрабатывает причину остановки ответа и расход токенов
  • Хранит ключ API на сервере, а не в клиентском коде

Практика. Сделать консольный чат с историей диалога и выводом стоимости каждого ответа.

Middle ≈ 4 ч

  • Реализует повторы на 429 и 5xx с экспоненциальной паузой и таймауты
  • Делает тонкую абстракцию над провайдерами для смены модели конфигурацией

Практика. Написать клиент с повторами, таймаутами и переключением между двумя провайдерами одной настройкой, покрыть тестами с подменой ответов.

Вопросы с собеседований

  • Что такое токены и контекстное окно LLM? Junior

    Токен — кусок текста (часть слова, слово, знак), с которым работает модель; контекстное окно — сколько токенов модель учитывает за раз: запрос плюс ответ.

  • Что такое temperature и top-p у языковой модели? Junior

    Параметры выборки следующего токена: temperature делает распределение острее или площе, top-p оставляет только самые вероятные токены с суммарной вероятностью p.
