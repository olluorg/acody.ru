Данные — NumPy и pandas

Полезно знать с Junior

Минимум работы с данными — подготовить датасет, посчитать метрики, разобрать логи.

ИИ-инженер регулярно работает с табличными данными: собирает набор вопросов для оценки качества, разбирает логи запросов, считает метрики по экспериментам, готовит данные для дообучения.

Что важно знать

  • NumPy: массивы и векторные операции — эмбеддинги это массивы чисел, косинусное сходство — скалярное произведение нормированных векторов.
  • pandas: чтение CSV и JSON, фильтрация, groupby, объединение таблиц.
  • Циклы и apply медленные — векторные операции быстрее в десятки раз.
  • Jupyter-ноутбуки — для исследования и прототипов, но не для продакшен-кода.

Критерии освоения

Junior ≈ 8 ч

  • Загружает логи запросов в pandas, фильтрует, группирует и строит сводную таблицу
  • Считает косинусное сходство векторов в NumPy без циклов
  • Использует ноутбук для исследования и переносит готовый код в модули

Практика. По логу из 10 тысяч запросов к ассистенту посчитать распределение тем, среднюю стоимость и долю ошибок по дням.

Вопросы с собеседований

  • Как работают groupby и merge в pandas и какие у них ловушки? Junior

    groupby — разбить, применить агрегат, собрать (split-apply-combine): df.groupby("city")["amount"].agg(["sum", "mean"]). merge — соединение таблиц по ключам, как SQL JOIN…

  • Почему apply и циклы в pandas медленные и как писать быстрее? Middle

    Векторные операции над столбцами (df["a"] df["b"], np.where, .str, .dt) выполняются в C над массивами. apply по строкам и циклы iterrows вызывают Python-функцию на каждую строку …
