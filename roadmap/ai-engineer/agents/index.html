Инструменты и агенты

Основа

Модель, которая вызывает функции, — tool calling, циклы агентов, MCP и фреймворки.

Вызов инструментов — модель получает описание функций и вместо текста может ответить «вызови get_order(id=42)». Код выполняет функцию, возвращает результат модели, и она продолжает. Агент — цикл, в котором модель сама решает, какие инструменты вызывать и когда задача решена.

пользователь → модель → вызов инструмента → результат → модель → … → ответ

Агенты — самая обсуждаемая и самая рискованная часть LLM-разработки: гибкость оплачивается непредсказуемостью, стоимостью и сложностью отладки. Хорошее правило — начинать с простейшей схемы (один вызов, фиксированная цепочка шагов) и добавлять автономию только там, где она действительно нужна.

Темы этапа

  • Вызов инструментов Основа

    Описание функций для модели, выполнение вызовов и обработка результатов.

  • Проектирование агентов Основа

    Цепочки, маршрутизация, оркестратор и исполнители — и почему агенты ломаются.

  • Model Context Protocol Основа

    Открытый протокол подключения инструментов и данных к LLM-приложениям.

  • Фреймворки для агентов и RAG Полезно знать

    LangChain, LangGraph, LlamaIndex и SDK провайдеров — когда помогают, а когда мешают.

Вопросы с собеседований

  • Что такое вызов инструментов (tool calling) и агенты? Middle

    Модель получает описания инструментов (имя, параметры по схеме) и вместо текста может вернуть запрос на вызов; вызывает их код приложения и отдаёт результат обратно модели.

  • Как проектировать LLM-агента и почему агенты ломаются? Middle

    Агент — цикл: модель решает, какой инструмент вызвать, получает результат и решает дальше, пока задача не решена (паттерн ReAct: рассуждение → действие → наблюдение). Начинать…
