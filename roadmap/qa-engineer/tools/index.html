Инструменты

Основа

Git, командная строка и Docker — то, чем тестировщик пользуется каждый день.

Тестировщик работает рядом с разработкой: берёт сборки из веток, читает логи на сервере, поднимает окружение в контейнерах. Без Git, терминала и Docker на этом пути трудно.

Темы этапа

  • Основы Git Основа

    Коммиты, индекс, ветки, слияние и откат — команды, которыми пользуются каждый день.

  • Командная строка Основа

    Навигация, файлы, процессы, переменные окружения и пайпы — работа в терминале без страха.

  • Docker Основа

    Контейнеры для воспроизводимого запуска сервиса — Dockerfile, образы, compose.
