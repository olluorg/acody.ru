Стили в React

CSS Modules, Tailwind, CSS-in-JS и UI-библиотеки компонентов.

Что важно знатьТемыКритерии освоенияПроверка знанийВопросы

React не диктует способ стилизации — выбор за проектом.

способкогда
CSS Modulesизолированные классы, обычный CSS, без рантайма
Tailwindбыстрая вёрстка утилитами, единая дизайн-система
CSS-in-JS (styled-components, Emotion)старые проекты, динамические стили из props
UI-библиотеки (MUI, Ant Design, shadcn/ui, Mantine)готовые доступные компоненты

Что важно знать

  • CSS-in-JS с рантаймом плохо сочетается с серверными компонентами — новые проекты чаще берут CSS Modules или Tailwind.
  • shadcn/ui — не зависимость, а копируемые в проект компоненты на Radix и Tailwind: полный контроль над кодом.
  • Условные классы — утилита clsx.
  • Общие токены (цвета, отступы) — в CSS-переменных, чтобы тема менялась без перерисовки React.

Темы этапа

  • Организация стилей — БЭМ, CSS Modules, Tailwind Основа

    Как не утонуть в стилях большого проекта — соглашения об именах, изоляция и утилитарный подход.

Что такое CSS Modules и чем они отличаются от CSS-in-JS?Junior

Что такое утилитарный CSS (Tailwind) и какие у него плюсы и минусы?Junior
