Компоненты, props и state

Основа с Junior

Из чего строится React-приложение — компоненты, однонаправленный поток данных, списки и ключи.

Props — входные данные от родителя, только для чтения. State — собственное состояние компонента; его изменение вызывает перерисовку. Данные текут сверху вниз, события — снизу вверх через колбэки.

Что важно знать

  • Состояние меняют только через сеттер и неизменяемо: новый объект или массив, а не push в старый — иначе React не заметит изменения.
  • Обновление состояния асинхронно и пакетное; зависимое от предыдущего значения — через функцию: setN(n => n + 1).
  • Подъём состояния: общее для двух компонентов состояние хранят в ближайшем общем родителе.
  • Ключи в списках — стабильный идентификатор элемента, не индекс: иначе при вставке и удалении путаются состояние и поля ввода.
  • Композиция через children вместо глубокой передачи props.
  • Производное значение вычисляют при рендере, а не хранят в отдельном state.

Критерии освоения

Junior ≈ 8 ч

  • Разделяет props и state, поднимает общее состояние в ближайшего родителя
  • Обновляет состояние неизменяемо и через функцию, если оно зависит от предыдущего
  • Использует стабильные ключи в списках

    props — входные данные от родителя, компонент их только читает. state — собственные данные компонента, меняются через setState и вызывают перерисовку. Данные текут сверху вниз…

  • Почему в React нельзя изменять состояние напрямую? Junior

    React узнаёт об изменении, сравнивая ссылки (Object.is). Мутация (items.push(x), user.name = ...) оставляет ссылку прежней — перерисовки не будет, а memo и useEffect не увидят…

  • Что такое виртуальный DOM и зачем в списках нужен key? Junior

    Компонент возвращает описание интерфейса (дерево React-элементов). При обновлении React сравнивает новое дерево со старым (reconciliation) и применяет к настоящему DOM минимальные…

  • Как поделиться состоянием между соседними компонентами — что значит «поднять состояние»? Junior
