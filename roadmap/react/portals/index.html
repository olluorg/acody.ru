Порталы

Полезно знать с Middle

Отрисовка модальных окон и подсказок вне родительского DOM-узла.

createPortal(children, domNode) рисует компонент в другом месте DOM — обычно в конце body, — оставляя его в дереве React.

return createPortal(<div className="modal">{children}</div>, document.body);

Что важно знать

  • Решает проблемы overflow: hidden и z-index у родителей для модальных окон, выпадающих меню и подсказок.
  • События из портала всплывают по дереву React, а не DOM: клик в модальном окне дойдёт до обработчика родительского компонента.
  • Для модальных окон — также управление фокусом и Escape; нативный <dialog> решает многое из коробки.

Критерии освоения

Middle ≈ 2 ч

  • Рендерит модальные окна и подсказки через порталы с управлением фокусом
  • Объясняет всплытие событий из портала по дереву React

Практика. Сделать доступное модальное окно на портале с ловушкой фокуса и закрытием по Escape.

  • Как обеспечить работу интерфейса с клавиатуры и управление фокусом? Junior

    Все действия должны быть доступны с клавиатуры: Tab — перемещение по интерактивным элементам, Enter и пробел — активация, Esc — закрыть окно, стрелки — внутри составных виджетов…
