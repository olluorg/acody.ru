Тестирование React

Основа с Junior

Testing Library, тесты хуков и сквозные сценарии.

Компоненты тестируют как пользователь: найти кнопку по роли и подписи, нажать, проверить видимый результат. Внутреннее состояние и число рендеров не проверяют.

render(<Counter />);
await userEvent.click(screen.getByRole("button", { name: /нажато/i }));
expect(screen.getByRole("button")).toHaveTextContent("Нажато 1");

Что важно знать

  • Стек: Vitest (или Jest) + React Testing Library + user-event.
  • Сеть — через MSW: те же обработчики работают в тестах и в разработке.
  • Компоненты с провайдерами (роутер, кэш запросов, тема) — общая функция renderWithProviders.
  • Хуки — renderHook.
  • Сквозные сценарии — Playwright.

Темы этапа

  • Юнит-тесты и тесты компонентов Основа

    Vitest и Testing Library — проверять поведение, а не реализацию.

  • Сквозные тесты — Playwright Основа

    Сценарии в настоящем браузере — вход, оформление заказа, оплата.

Критерии освоения

Junior ≈ 4 ч

  • Тестирует компоненты через Testing Library и user-event

Практика. Покрыть тестами 3 компонента приложения.

Middle ≈ 4 ч

  • Тестирует компоненты с провайдерами и сетью через MSW, хуки — через renderHook

Практика. Сделать общую функцию renderWithProviders и покрыть тестами страницу с загрузкой данных.
