Context

Основа с Junior

Передача данных вглубь дерева без проброса props — и почему это не менеджер состояния.

const ThemeContext = createContext("light");

function App() {
  const [theme, setTheme] = useState("dark");
  return <ThemeContext value={theme}><Page /></ThemeContext>;
}

function Button() {
  const theme = useContext(ThemeContext);
  return <button className={theme}>Ок</button>;
}

Что важно знать

  • Подходит для редко меняющихся данных, нужных многим: тема, язык, текущий пользователь.
  • При изменении значения перерисовываются все компоненты, читающие контекст. Объект-значение, созданный заново на каждом рендере, перерисует их всегда — оборачивать в useMemo или разделять контексты.
  • Часто проблему проброса props лучше решает композиция через children.
  • Для часто меняющегося общего состояния — Zustand, Redux Toolkit или библиотеки серверного состояния.

Критерии освоения

Junior ≈ 3 ч

  • Передаёт тему или пользователя через Context

Практика. Сделать переключатель темы на Context.

Middle ≈ 3 ч

  • Избегает лишних перерисовок — мемоизация значения, разделение контекстов
  • Объясняет, почему Context — не менеджер состояния

Практика. Найти и устранить лишние перерисовки из-за контекста с помощью React DevTools Profiler.
