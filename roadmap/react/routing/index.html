Маршрутизация

Основа с Junior

Несколько страниц в одностраничном приложении — React Router, вложенные маршруты, загрузка данных.

Одностраничное приложение (SPA) меняет адрес через History API без перезагрузки страницы, а маршрутизатор решает, какой компонент показать.

Что важно знать

  • Маршруты, параметры (/orders/:id), вложенные маршруты с общим каркасом, страница 404.
  • Навигация ссылками (<Link>), а не onClick с переходом — иначе ломаются открытие в новой вкладке и доступность.
  • Защищённые маршруты: проверка авторизации и перенаправление на вход.
  • Загрузка данных до показа страницы (loaders) убирает «водопад» запросов из эффектов.
  • Разделение кода по маршрутам: lazy(() => import("./Orders")).
  • Состояние фильтров и пагинации — в параметрах адреса: ссылкой можно поделиться, кнопка «назад» работает.
  • В Next.js маршруты задаются структурой файлов.

Критерии освоения

Junior ≈ 4 ч

  • Настраивает маршруты, параметры и вложенные раскладки в React Router

Практика. Сделать приложение из 4 страниц с вложенной раскладкой и страницей 404.

Middle ≈ 4 ч

  • Загружает данные до показа страницы, защищает маршруты и хранит фильтры в URL

Практика. Добавить загрузчики данных, защищённые маршруты и фильтры каталога в параметрах адреса.
