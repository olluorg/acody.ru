Redux Toolkit

Альтернатива с Middle

Предсказуемое глобальное хранилище — слайсы, действия, селекторы.

Что важно знатьКритерии освоенияПроверка знанийВопросыДокументация

Redux хранит состояние приложения в одном хранилище и меняет его только через действия, которые обрабатывают чистые функции-редьюсеры. Redux Toolkit — современный способ писать Redux без шаблонного кода.

const cart = createSlice({
  name: "cart",
  initialState: { items: [] },
  reducers: {
    added(state, action) { state.items.push(action.payload); },   // Immer: можно «мутировать»
  },
});

Что важно знать

  • Однонаправленный поток: компонент → dispatch(action) → редьюсер → новое состояние → подписчики через useSelector.
  • Селекторы подписывают компонент на часть состояния — перерисовка только при её изменении.
  • Redux DevTools: история действий и «путешествие во времени».
  • Сильные стороны — крупные приложения и команды; для небольших проектов часто избыточен.
  • На собеседованиях до сих пор спрашивают классический Redux: что такое action, reducer, middleware, почему редьюсер должен быть чистым.

Почему в React нельзя изменять состояние напрямую?Junior

React узнаёт об изменении, сравнивая ссылки (Object.is). Мутация (items.push(x), user.name = ...) оставляет ссылку прежней — перерисовки не будет, а memo и useEffect не увидят изменений. Состояние обновляют новым объектом: spread, map, filter, toSorted.
