О теме

React описывает интерфейс функциями-компонентами, которые возвращают JSX. Когда меняется состояние, React вызывает компонент заново, сравнивает новое дерево элементов со старым и применяет к DOM минимальные изменения.

function Counter({ step = 1 }) {
  const [n, setN] = useState(0);
  return <button onClick={() => setN(n + step)}>Нажато {n}</button>;
}

Карта выше охватывает то, что спрашивают на собеседованиях: props и state, хуки и их правила, когда и почему компонент перерисовывается, управление состоянием, формы, маршрутизация и серверный рендеринг.

Документация react.dev — один из лучших учебников в индустрии; её раздела Learn достаточно, чтобы уверенно начать.

Чем state отличается от props в React?Junior
