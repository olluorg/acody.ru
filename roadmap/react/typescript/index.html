    Что важно знать

    • Props — через type или interface; React.FC не обязателен.
    • React.ReactNode для children, React.ComponentProps<"input"> — унаследовать атрибуты нативного элемента.
    • Состояние, которое начинается с null, — явный тип в useState.
    • Типы событий: React.ChangeEvent<HTMLInputElement>, React.FormEvent.
    • Контекст без значения по умолчанию — свой хук с проверкой, что провайдер есть.
    • Дженерик-компоненты: function List<T>({ items, render }: …).

    Зачем нужен TypeScript и чем any отличается от unknown?Junior

    TypeScript добавляет к JavaScript статические типы, которые проверяются при компиляции и стираются в итоговом JS. Польза: ошибки до запуска, автодополнение, безопасный рефакторинг, типы как документация. any отключает проверку; unknown — «что угодно», но…

    Чем interface отличается от type в TypeScript и что такое утилитарные типы?Junior

    Оба описывают форму объекта. interface — расширяется через extends и сливается при повторном объявлении (удобно для расширения чужих типов). type — умеет больше: объединения, пересечения, кортежи, условные и сопоставленные типы. Утилиты строят новые типы из…

    Что такое сужение типов в TypeScript?Junior
