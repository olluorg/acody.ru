Композиция компонентов

Основа с Junior

children, слоты, render props и HOC — как переиспользовать интерфейс без наследования.

В React не наследуют компоненты — их составляют.

function Card({ title, actions, children }) {
  return (
    <section className="card">
      <header>{title}{actions}</header>
      {children}
    </section>
  );
}

<Card title="Корзина" actions={<ClearButton />}>
  <CartItems />
</Card>

Что важно знать

  • children и именованные «слоты» через props — основной способ строить обёртки: модальные окна, раскладки, карточки.
  • Композиция решает «проброс props через пять уровней» чаще, чем контекст.
  • Render props (<List renderItem={…}/>) и HOC (withAuth(Component)) — старые приёмы переиспользования логики; сейчас их почти везде заменили пользовательские хуки, но в старом коде и библиотеках они встречаются.
  • Составные компоненты (<Tabs><Tabs.List/><Tabs.Panel/></Tabs>) с общим контекстом — паттерн UI-библиотек.

Критерии освоения

Junior ≈ 3 ч

  • Использует children и слоты для обёрток — модальные окна, карточки, раскладки

Практика. Сделать компонент Card со слотами для заголовка, действий и содержимого.

Middle ≈ 4 ч

  • Строит составные компоненты с общим контекстом
  • Заменяет render props и HOC пользовательскими хуками

Практика. Сделать составной компонент Tabs (Tabs.List, Tabs.Tab, Tabs.Panel) с доступностью.
