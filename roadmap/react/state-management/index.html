Управление состоянием

Основа с Middle

Локальное, глобальное и серверное состояние — Context, Redux Toolkit, Zustand, TanStack Query.

Первое правило — разделить состояние по природе:

видпримеринструмент
локальноеоткрыт ли выпадающий списокuseState
общее клиентскоетема, корзина, авторизацияContext, Zustand, Redux Toolkit
серверноесписок заказовTanStack Query, RTK Query, SWR
в адресефильтры, номер страницыпараметры URL
формыполя и ошибкиReact Hook Form

Что важно знать

  • Большинство «глобального состояния» на деле — кэш серверных данных; специализированные библиотеки дают кэширование, повторы, обновление в фоне и инвалидацию.
  • Context — передача данных вглубь, а не менеджер состояния: при изменении значения перерисовываются все подписчики.
  • Redux Toolkit — предсказуемость, devtools, строгая структура; хорош для больших команд. Zustand — минимум кода.
  • Не класть всё в глобальное хранилище: чем ближе состояние к месту использования, тем проще код.

Темы этапа

  • Context Основа

    Передача данных вглубь дерева без проброса props — и почему это не менеджер состояния.

  • Серверное состояние — TanStack Query Основа

    Загрузка, кэширование и обновление данных с сервера без самописных эффектов.

  • Redux Toolkit Альтернатива

    Предсказуемое глобальное хранилище — слайсы, действия, селекторы.

  • Zustand Альтернатива

    Минималистичное глобальное хранилище на хуках.

Критерии освоения

Middle ≈ 4 ч

  • Разделяет состояние на локальное, глобальное, серверное, в URL и в формах и выбирает инструмент для каждого

Практика. Провести аудит состояния проекта и перенести фильтры в URL, данные сервера — в кэш запросов.

Senior ≈ 4 ч

  • Обосновывает подход к состоянию для большого приложения и правила для команды

Практика. Описать правила работы с состоянием для команды с примерами и антипримерами.

Вопросы с собеседований

  • Как управлять состоянием в React-приложении — Context, Redux, Zustand, серверное состояние? Junior

    Сначала — локальное состояние и подъём к общему предку. Context — передать редко меняющиеся данные глубоко (тема, пользователь, язык) без прокидывания props. Глобальное хранилище…
