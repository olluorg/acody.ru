React Native

Полезно знать с Middle

Мобильные приложения на React для iOS и Android.

React Native использует те же компоненты, хуки и подходы, но рисует нативные элементы интерфейса вместо HTML: <View>, <Text>, <Pressable> вместо div и button.

Что важно знать

  • Expo — стандартный способ начать: сборка, обновления, доступ к API устройства.
  • Стили — объектами, раскладка на Flexbox (по умолчанию колонкой).
  • Навигация — React Navigation или Expo Router.
  • Новая архитектура (Fabric, TurboModules) убрала медленный мост между JavaScript и нативным кодом.
  • Для фронтендера на React — самый короткий путь в мобильную разработку.

Критерии освоения

Middle ≈ 16 ч

  • Создаёт мобильное приложение на Expo с навигацией и нативными компонентами
  • Объясняет отличия от веба — стили, раскладка, жизненный цикл

Практика. Сделать на Expo мобильный клиент своего веб-приложения из трёх экранов.
