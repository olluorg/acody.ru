Next.js

Основа с Middle

Мета-фреймворк на React — маршрутизация по файлам, SSR и SSG, серверные компоненты.

Next.js добавляет к React то, чего в нём нет: маршрутизацию по структуре файлов, серверный рендеринг и статическую генерацию, загрузку данных на сервере, оптимизацию картинок и шрифтов, API-обработчики.

app/
  layout.tsx           общий каркас
  page.tsx             /
  orders/
    page.tsx           /orders
    [id]/page.tsx      /orders/42

Что важно знать

  • App Router: компоненты по умолчанию серверные; "use client" — граница клиентского кода.
  • Данные загружаются прямо в серверных компонентах (await fetch, запрос в БД), без отдельного API.
  • Стратегии: статическая страница, динамическая на каждый запрос, пересборка по времени или по событию.
  • Server Actions — функции на сервере, вызываемые из форм.
  • Кэширование в Next.js многоуровневое — частый источник «почему данные не обновились».
  • Альтернатива — React Router в режиме фреймворка (бывший Remix).

Темы этапа

  • Серверные компоненты Основа

    Компоненты, которые выполняются только на сервере и не попадают в бандл.

  • Серверный рендеринг и мета-фреймворки Основа

    CSR, SSR, SSG и гидратация — где и когда собирается HTML; Next.js и аналоги.

Критерии освоения

  • Строит приложение на App Router — маршруты по файлам, раскладки, загрузка данных на сервере
  • Использует Server Actions для форм

Практика. Сделать на Next.js блог или каталог с серверными компонентами, формой на Server Actions и метаданными для SEO.

Senior ≈ 6 ч

  • Проектирует кэширование и стратегии рендеринга страниц Next.js

Практика. Разобрать и описать поведение кэша Next.js в своём приложении и настроить инвалидацию по событию.
