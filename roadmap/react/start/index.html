Старт и JSX

Основа с Junior

Создать проект на Vite, понять JSX и первый компонент — с чего начинается React.

React — библиотека для построения интерфейсов из компонентов. Компонент — функция, которая принимает данные и возвращает описание интерфейса на JSX. Когда данные меняются, React вызывает функцию заново и обновляет только изменившиеся части DOM.

npm create vite@latest shop -- --template react-ts
cd shop && npm install && npm run dev

Create React App устарел и больше не развивается: для SPA берут Vite, для сайтов с SSR — Next.js или React Router в режиме фреймворка.

Что важно знать до старта

JavaScript: деструктуризация, spread, стрелочные функции, методы массивов map и filter, модули, промисы. Без уверенного JS React кажется магией, а ошибки — непонятными.

Темы этапа

  • JSX и условный рендеринг Основа

    Разметка внутри JavaScript — выражения, атрибуты, условия и фрагменты.

  • События Основа

    Обработчики событий, передача колбэков детям и синтетические события.

Критерии освоения

Junior ≈ 4 ч

  • Создаёт React-проект на Vite с TypeScript и запускает его
  • Объясняет, почему React перерисовывает интерфейс при изменении состояния

Практика. Создать проект на Vite, сделать в нём счётчик и список с добавлением элементов.
