Старт и JSX

Основа с Junior

Создать проект на Vite, понять JSX и первый компонент — с чего начинается React.

ТемыКритерии освоенияПроверка знанийВопросыДокументация

React — библиотека для построения интерфейсов из компонентов. Компонент — функция, которая принимает данные и возвращает описание интерфейса на JSX. Когда данные меняются, React вызывает функцию заново и обновляет только изменившиеся части DOM.

npm create vite@latest shop -- --template react-ts
cd shop && npm install && npm run dev

Create React App устарел и больше не развивается: для SPA берут Vite, для сайтов с SSR — Next.js или React Router в режиме фреймворка.

Что важно знать до старта

JavaScript: деструктуризация, spread, стрелочные функции, методы массивов map и filter, модули, промисы. Без уверенного JS React кажется магией, а ошибки — непонятными.

Как создать React-проект и почему React перерисовывает интерфейс при изменении состояния?Junior

Проект создают сборщиком Vite: npm create vite@latest app -- --template react-ts, затем npm install и npm run dev. React декларативный: вы описываете, как интерфейс выглядит при данном состоянии, а не какие DOM-операции выполнить. Когда состояние меняется…

Полный разбор
Что такое JSX и как вставлять в него выражения и фрагменты?Junior

JSX — синтаксис, который компилируется в вызовы создания элементов (<div className="a"> → jsx("div", {className: "a"})). В фигурных скобках — любое выражение JavaScript: переменная, вызов функции, тернарный оператор, map по массиву; инструкции (if, for) …

Полный разбор
Чем state отличается от props в React?Junior

props — входные данные от родителя, компонент их только читает. state — собственные данные компонента, меняются через setState и вызывают перерисовку. Данные текут сверху вниз; ребёнок сообщает об изменениях родителю через колбэки в props. Общее состояние…

Полный разбор
Как сделать условный рендеринг в React и в чём ловушка с && и нулём?Junior

Способы: тернарный оператор {cond ? <A/> : <B/>}, логическое И {cond && <A/>}, ранний return из компонента, переменная с элементом. Ловушка &&: если слева число 0, React его выведет на страницу ({items.length && <List/>} покажет «0»). Лечится явным булевым…
