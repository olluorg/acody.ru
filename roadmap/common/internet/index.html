Как работает интернет

Основа с Junior

Клиент, сервер, протоколы и путь запроса от адресной строки до ответа — основа, на которой стоит любая веб-разработка.

Интернет — сеть сетей: компьютеры обмениваются пакетами по протоколу IP, а поверх него работают TCP (надёжная доставка), UDP (быстрая без гарантий) и прикладные протоколы — HTTP, WebSocket, DNS. Веб-приложение — это всегда клиент (браузер, мобильное приложение, другой сервис) и сервер, которые разговаривают по HTTP.

Путь запроса

  1. Браузер разбирает адрес и находит IP сервера через DNS.
  2. Открывает TCP-соединение (для HTTP/3 — QUIC поверх UDP) и выполняет TLS-рукопожатие.
  3. Отправляет HTTP-запрос, сервер отвечает HTML.
  4. Браузер разбирает HTML, догружает CSS, JavaScript, картинки и отрисовывает страницу.

Что важно знать

  • Чем отличаются IP-адрес, домен и URL.
  • Зачем нужны TCP и UDP и чем они отличаются.
  • Что такое порт и почему у HTTPS по умолчанию 443.
  • Где по пути запроса появляются задержки: DNS, рукопожатия, расстояние до сервера, размер ответа.

Вопрос «что происходит, когда вы вводите адрес в браузере» задают на собеседованиях и фронтендерам, и бэкендерам: ответ показывает, насколько цельно человек видит систему.

Вопросы с собеседований

  • Что происходит, когда вы вводите адрес сайта в браузере и нажимаете Enter? Junior

    DNS находит IP → TCP-рукопожатие → TLS-рукопожатие → HTTP-запрос → сервер (балансировщик, приложение, база) → ответ → браузер разбирает HTML, догружает ресурсы и рисует страницу.

  • Расскажите про модель OSI и стек TCP/IP. Junior

    Сеть устроена слоями: каждый решает свою задачу и пользуется нижним. OSI — учебная модель из 7 уровней, на практике работает TCP/IP из 4.

  • Чем TCP отличается от UDP? Junior

    TCP — надёжный упорядоченный поток байтов с установкой соединения. UDP — отдельные датаграммы без гарантий: быстро и просто.

  • Как работает DNS? Junior

    DNS — распределённая иерархическая база «имя → адрес». Рекурсивный резолвер спрашивает по цепочке: корневые серверы → серверы зоны .ru → авторитетный сервер домена.

  • Что происходит, когда вы вводите адрес сайта в браузере? Junior

    Браузер находит IP через DNS, устанавливает соединение (TCP, TLS для HTTPS), отправляет HTTP-запрос, сервер возвращает ответ, браузер отрисовывает страницу и догружает ресурсы.
