Git и контроль версий

Основа

История изменений, ветки и совместная работа над кодом — инструмент, без которого не работает ни одна команда.

Git хранит историю проекта как цепочку коммитов — снимков файлов с автором, сообщением и ссылкой на родителя. Ветка — подвижный указатель на коммит. Работа в команде строится вокруг удалённого репозитория (GitHub, GitLab, Gitflic) и pull request — предложения влить изменения с ревью и автоматическими проверками.

На собеседованиях Git редко спрашивают отдельно, но ждут уверенного владения: объяснить, чем merge отличается от rebase, как откатить неудачный коммит и как устроен процесс ревью в вашей команде.

Темы

  • Основы Git Основа

    Коммиты, индекс, ветки, слияние и откат — команды, которыми пользуются каждый день.

  • Pull request и код-ревью Основа

    Как команды вливают изменения — ветки, pull request, ревью, автоматические проверки и стратегии ветвления.
