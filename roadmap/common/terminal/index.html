Командная строка

Основа с Junior

Навигация, файлы, процессы, переменные окружения и пайпы — работа в терминале без страха.

Что важно знатьКритерии освоенияПроверка знанийВопросыРазборыДокументация

Терминал нужен каждый день: запустить проект, поставить зависимости, работать с Git, зайти на сервер, посмотреть логи, быстро найти что-то в сотне файлов.

cd ~/projects/shop && ls -la          # перейти и посмотреть файлы
grep -rn "TODO" src/ | head            # найти по содержимому
cat app.log | grep ERROR | wc -l       # пайп: посчитать ошибки
export API_URL=http://localhost:8080   # переменная окружения
ps aux | grep node; kill 12345         # процессы

Что важно знать

  • Пути: абсолютные и относительные, ~, . и ...
  • Файлы: ls, cp, mv, rm (без корзины!), mkdir -p, cat, less, head, tail -f.
  • Поиск: grep, find; современные rg и fd быстрее.
  • Пайпы | и перенаправление >, >>, 2>&1.
  • Переменные окружения и PATH — почему «команда не найдена».
  • Права и sudo, chmod +x для скриптов.
  • Процессы: ps, top, kill, Ctrl+C.
  • ssh для входа на сервер, curl для запросов к API.
  • На Windows — WSL: большая часть инструментов разработки рассчитана на Unix-окружение.

Критерии освоения

Junior ≈ 8 ч

  • Перемещается по файловой системе, создаёт, копирует и удаляет файлы без файлового менеджера
  • Находит строку в сотне файлов через grep и считает совпадения пайпом
  • Задаёт переменные окружения и объясняет, почему команда «не найдена» (PATH)
  • Заходит на сервер по SSH-ключу и смотрит логи сервиса через tail -f

Практика. Неделю работать с проектом только из терминала — запуск, тесты, Git, поиск по коду, просмотр логов — и записать 20 команд, которые пригодились.

Какими командами вы диагностируете проблему на Linux-сервере?Middle

Порядок: жив ли процесс (systemctl status, ps) → логи (journalctl, файлы приложения) → ресурсы (top, free, df, iostat) → сеть (ss -tlnp — слушает ли порт, curl localhost, dig) → что изменилось (деплой, конфиг, сертификат). Первые 60 секунд: uptime, dmesg |…

Полный разбор
Как устроены права доступа к файлам в Linux?Junior

У файла есть владелец, группа и три набора прав — для владельца, группы и остальных: чтение (r = 4), запись (w = 2), выполнение (x = 1). chmod 755 — владелец rwx (7), группа и остальные r-x (5). Для каталога x — право войти в него, r — увидеть список файлов.

Полный разбор
Как работать с файлами в командной строке Linux?Junior

pwd — где я, ls -la — что здесь (со скрытыми и правами), cd — перейти (cd .. — вверх, cd ~ — домой, cd - — назад). mkdir -p — создать каталоги, touch — пустой файл, cp -r — копировать (с каталогами), mv — переместить или переименовать, rm — удалить, rm -r …

Полный разбор
Как найти текст в файлах и обработать вывод через пайпы?Junior

grep "текст" файл — строки с совпадением; -r — рекурсивно по каталогу, -i — без учёта регистра, -n — номера строк, -c — число совпадений, -v — строки без совпадения. Пайп | передаёт вывод одной команды на вход другой: grep ERROR app.log | wc -l — посчитать…

Полный разбор
Что такое переменные окружения и PATH и почему команда «не найдена»?Junior

Переменные окружения — пары «имя=значение», которые процесс получает от родителя: настройки, пути, секреты. Задать для текущей сессии и дочерних процессов — export NAME=value, для одной команды — NAME=value команда, посмотреть — echo $NAME или env. PATH …

Полный разбор
Как устроен доступ по SSH-ключам и зачем нужен bastion-хост?Junior

Пара ключей: закрытый хранится у пользователя, открытый кладут на сервер в ~/.ssh/authorized_keys. При входе сервер проверяет, что клиент владеет закрытым ключом, — сам ключ по сети не передаётся. Bastion (jump host) — единственная точка входа во внутреннюю…
