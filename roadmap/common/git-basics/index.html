Основы Git

Основа с Junior

Коммиты, индекс, ветки, слияние и откат — команды, которыми пользуются каждый день.

У файла в Git три состояния: изменён в рабочей копии, добавлен в индекс (git add) и сохранён в коммите (git commit).

git switch -c feature/cart     # новая ветка
git add -p                     # добавить изменения по частям
git commit -m "Корзина: пересчёт скидки"
git fetch && git rebase origin/main   # подтянуть свежий main
git push -u origin feature/cart

Что важно знать

  • merge создаёт коммит слияния и сохраняет историю как была; rebase переписывает коммиты поверх другой ветки — история линейная, но опубликованные коммиты переписывать нельзя.
  • Откат: git revert — новый коммит, отменяющий старый (безопасно для общих веток); git reset — передвинуть ветку назад (только локально).
  • git stash — временно убрать незакоммиченные изменения.
  • git log --oneline --graph, git diff, git blame — чтение истории.
  • Хорошее сообщение коммита объясняет зачем, а не перечисляет файлы.
  • .gitignore — не коммитить зависимости, сборку и секреты.

Критерии освоения

Junior ≈ 6 ч

  • Создаёт ветку, делает осмысленные коммиты и отправляет их в удалённый репозиторий
  • Объясняет разницу между merge и rebase и не переписывает опубликованную историю
  • Отменяет изменения через revert, reset и restore в подходящих ситуациях
  • Разрешает конфликт слияния и проверяет результат тестами

Практика. Провести учебный проект через 10 веток с pull request, специально создать и разрешить 3 конфликта, откатить один неудачный коммит через revert.

Вопросы с собеседований

  • Как работать с ветками и коммитами в Git — от создания ветки до push? Junior

    Работа идёт в отдельной ветке от актуальной main: git switch -c feature/login. Изменения добавляют в индекс (git add) и фиксируют коммитом с осмысленным сообщением: что изменено и…

  • Чем merge отличается от rebase и почему нельзя переписывать опубликованную историю? Junior

    merge соединяет две ветки коммитом слияния, сохраняя историю как была. rebase переносит коммиты ветки поверх другой, создавая новые коммиты с другими хешами — история становится…

  • Как отменить изменения в Git — restore, reset и revert? Junior

    git restore файл — отменить незакоммиченные изменения в рабочей копии; git restore --staged файл — убрать из индекса. git reset двигает ветку на другой коммит: --soft оставляет…

  • Как разрешить конфликт слияния в Git? Junior

    Конфликт — обе ветки изменили одни и те же строки, и Git не знает, что оставить. В файле появляются маркеры: между <<<<<<< и ======= — ваша версия, между ======= и >>>>>>> …
