DNS

Основа с Junior

Система, которая превращает имя сайта в IP-адрес, — записи, кэширование, TTL и типичные проблемы.

DNS — распределённый справочник «имя → адрес». Браузер спрашивает рекурсивный резолвер (провайдера или публичный), тот идёт по цепочке: корневые серверы → серверы зоны .ru → авторитетный сервер домена. Ответ кэшируется на время TTL на каждом уровне.

Основные записи

записьчто хранит
A / AAAAIPv4 / IPv6 адрес
CNAMEпсевдоним на другое имя
MXпочтовые серверы
TXTпроверки владения, SPF, DKIM
NSкакие серверы отвечают за зону

Что важно знать

  • Смена записи распространяется не мгновенно — старый ответ живёт до истечения TTL; перед переездом TTL заранее уменьшают.
  • CNAME нельзя поставить на корень домена (example.com) — для этого у провайдеров есть ALIAS или ANAME.
  • Проверка: dig example.com, nslookup.
  • DNS-запрос — часть задержки первой загрузки; <link rel="dns-prefetch"> и preconnect помогают браузеру начать раньше.

Критерии освоения

Junior ≈ 2 ч

  • Объясняет, как браузер находит IP по домену и что такое TTL
  • Проверяет записи домена через dig или nslookup

Практика. Посмотреть A, CNAME, MX и TXT записи трёх известных сайтов и объяснить, что означает каждая.

Middle ≈ 2 ч

  • Планирует смену DNS-записей с учётом TTL без простоя
  • Использует dns-prefetch и preconnect для сторонних доменов

Практика. Описать план переезда сайта на новый сервер через смену DNS без простоя с учётом TTL.

Вопросы с собеседований

  • Как работает DNS? Junior

    DNS — распределённая иерархическая база «имя → адрес». Рекурсивный резолвер спрашивает по цепочке: корневые серверы → серверы зоны .ru → авторитетный сервер домена.

  • Как проверить DNS-записи домена через dig или nslookup? Junior

    dig example.ru — A-запись (IPv4) и оставшийся TTL; dig example.ru AAAA, MX, TXT, CNAME, NS — другие типы; dig +short — только ответ. dig @8.8.8.8 example.ru — спросить конкретный…

  • Как сменить DNS-запись (например, переехать на новый сервер) без простоя? Middle

    Резолверы держат запись до истечения TTL, поэтому переключение не мгновенное. План: заранее (за время не меньше текущего TTL) понизить TTL до минут → поднять новый сервер и…

  • Что происходит, когда вы вводите адрес сайта в браузере и нажимаете Enter? Junior

    DNS находит IP → TCP-рукопожатие → TLS-рукопожатие → HTTP-запрос → сервер (балансировщик, приложение, база) → ответ → браузер разбирает HTML, догружает ресурсы и рисует страницу.

  • Что происходит, когда вы вводите адрес сайта в браузере? Junior

    Браузер находит IP через DNS, устанавливает соединение (TCP, TLS для HTTPS), отправляет HTTP-запрос, сервер возвращает ответ, браузер отрисовывает страницу и догружает ресурсы.
