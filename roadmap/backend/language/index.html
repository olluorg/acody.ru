Язык программирования

Основа

Java, Python или Go — основной инструмент бэкенд-разработчика; у каждого языка своя карта.

Принципы бэкенда одинаковы в любом языке, но работать нужно на одном — глубоко. На собеседованиях до половины вопросов — про язык: коллекции, многопоточность, устройство рантайма.

языкгде в Россиисильные стороны
Java (+ Spring)банки, маркетплейсы, крупный энтерпрайз — больше всего вакансийзрелая экосистема, производительность, Spring
Pythonвеб, ИИ и данные, автоматизация, стартапыскорость разработки, библиотеки для данных и ML
Goвысоконагруженные сервисы, инфраструктура, Авито, Озонпростота, горутины, быстрый старт и малое потребление памяти

Выбирайте по вакансиям в своём городе и по тому, что уже знаете. Второй язык осваивается за месяцы, когда первый выучен хорошо.

Темы этапа

  • Java Основа

    Самый востребованный язык бэкенда в России — от синтаксиса и коллекций до многопоточности, JVM и Spring.

  • Python Альтернатива

    Бэкенд на Python — язык, асинхронность, веб-фреймворки и инструменты.

  • Go Альтернатива

    Бэкенд на Go — срезы и интерфейсы, горутины и каналы, сервисы на стандартной библиотеке.
