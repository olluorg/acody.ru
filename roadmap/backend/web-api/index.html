Веб и API

Основа

HTTP, проектирование REST API, gRPC и другие стили, аутентификация и авторизация.

Бэкенд общается с миром через API: фронтенд, мобильные приложения, другие сервисы, партнёры. Хорошо спроектированный API понятен, предсказуем, безопасен и развивается без поломки клиентов.

Этап охватывает протокол HTTP, проектирование REST, альтернативные стили (gRPC, GraphQL, WebSocket, вебхуки) и то, как сервис узнаёт, кто к нему пришёл и что ему можно.

Темы этапа

  • HTTP и HTTPS Основа

    Протокол обмена между клиентом и сервером — методы, коды ответа, заголовки, кэширование, версии протокола и шифрование.

  • Проектирование REST API Основа

    Ресурсы, методы, коды ответа, пагинация, идемпотентность, версии и совместимость.

  • gRPC, GraphQL, WebSocket и вебхуки Полезно знать

    Когда REST не лучший выбор — межсервисное взаимодействие, гибкие запросы, реальное время.

  • Аутентификация и авторизация Основа

    Сессии и токены, JWT, OAuth 2.0 и OpenID Connect, роли и права доступа.
