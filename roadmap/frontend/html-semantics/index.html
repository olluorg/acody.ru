Семантическая разметка

Основа с Junior

Элементы по смыслу — заголовки, разделы, списки, ссылки и кнопки вместо безликих div.

<header>…логотип, навигация…</header>
<nav aria-label="Основная">…</nav>
<main>
  <article>
    <h1>Заголовок страницы</h1>
    <section><h2>Раздел</h2>…</section>
  </article>
  <aside>…связанное…</aside>
</main>
<footer>…</footer>

Что важно знать

  • Один <h1> на страницу и иерархия заголовков без пропусков — по ним скринридеры строят оглавление.
  • Ссылка (<a href>) — переход на другой адрес, кнопка (<button>) — действие на странице. Не наоборот.
  • Списки — <ul>/<ol>, таблицы с данными — <table> с <th>.
  • <img> всегда с alt: описание для смысловых картинок, пустой alt="" для декоративных.
  • Блочные и строчные элементы, вложенность (нельзя <div> внутри <p>).
  • Мета-теги в <head>: charset, viewport, title, description.

Критерии освоения

Junior ≈ 6 ч

  • Размечает страницу семантическими элементами — header, nav, main, article, section, footer
  • Строит иерархию заголовков без пропусков и использует ссылку для перехода, кнопку для действия
  • Пишет осмысленный alt для картинок и пустой для декоративных

Практика. Сверстать страницу статьи только семантическими тегами, проверить её валидатором W3C и скринридером.

    Семантические теги описывают смысл содержимого: header, nav, main (один на странице), article, section, aside, footer, заголовки h1–h6 по иерархии, button для действий, a для…

  • Что такое доступность веб-интерфейса и с чего её начинать? Junior

    Доступность — возможность пользоваться интерфейсом людям с нарушениями зрения, слуха, моторики, когнитивными особенностями, а также всем в неудобных условиях (солнце, одна рука)…

  • Какие мета-теги нужны странице — title, description, Open Graph? Junior

    title — заголовок во вкладке и в выдаче (до ~60 символов), meta description — сниппет (~150 символов), viewport — для мобильных, canonical — основной адрес страницы, robots …
