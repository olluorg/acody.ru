DOM и события

Основа с Junior

Поиск и изменение элементов, обработчики, всплытие и делегирование событий.

DOM — дерево объектов, которое браузер строит из HTML. JavaScript может находить узлы, менять их и подписываться на события.

const list = document.querySelector("#todo");
list.addEventListener("click", (e) => {
  const item = e.target.closest("li[data-id]");
  if (item) remove(item.dataset.id);       // делегирование
});

Что важно знать

  • Событие идёт в три фазы: перехват сверху вниз, цель, всплытие снизу вверх. Обработчики по умолчанию — на всплытии.
  • Делегирование: один обработчик на родителе вместо сотни на элементах — работает и для элементов, добавленных позже.
  • e.target — где произошло событие, e.currentTarget — где висит обработчик.
  • preventDefault() отменяет действие браузера, stopPropagation() — всплытие (злоупотреблять не стоит).
  • Частые события (scroll, input, resize) — через debounce или throttle; пассивные обработчики прокрутки.
  • Массовые изменения DOM — пачкой (DocumentFragment, replaceChildren), без чтения размеров между записями.
  • textContent вместо innerHTML для пользовательских данных — защита от XSS.

Критерии освоения

Junior ≈ 6 ч

  • Находит и изменяет элементы DOM, вешает и снимает обработчики
  • Применяет делегирование событий и объясняет всплытие и перехват
  • Вставляет пользовательские данные через textContent, а не innerHTML

Практика. Сделать список задач на чистом JS с добавлением, удалением и фильтрацией через один делегированный обработчик.

Вопросы с собеседований

  • Что такое всплытие и перехват событий и как работает делегирование? Junior

    Событие проходит три фазы: перехват (от window вниз к цели), цель, всплытие (от цели вверх). Обработчики по умолчанию срабатывают на всплытии. Делегирование — один обработчик на…

  • Чем debounce отличается от throttle? Junior

    Debounce — вызвать функцию, только когда события прекратились на N мс: поиск по вводу, сохранение черновика, resize. Throttle — вызывать не чаще раза в N мс, пока события идут…
