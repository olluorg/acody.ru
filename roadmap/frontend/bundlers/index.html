Сборщики — Vite и webpack

Основа с Junior

Dev-сервер, сборка для продакшена, tree shaking, разделение кода и хеши в именах.

Что важно знатьКритерии освоенияПроверка знанийВопросыДокументация

Vite — стандарт для новых проектов: в разработке отдаёт ES-модули браузеру почти без сборки (мгновенный старт и горячая перезагрузка), для продакшена собирает оптимизированный бандл. webpack — гибкий сборщик, который встречается в большом числе существующих проектов. Новое поколение — Rspack, Rolldown, Turbopack — написано на Rust ради скорости.

Что важно знать

  • Tree shaking — удаление неиспользуемого кода; работает с ES-модулями и без побочных эффектов при импорте.
  • Разделение кода (code splitting) — отдельные файлы для маршрутов и тяжёлых библиотек через import().
  • Хеш в имени (index-4f2a9c.js) — файлы можно кэшировать навсегда, новая сборка даёт новые имена.
  • Минификация и source maps — для отладки продакшен-кода.
  • Переменные окружения на этапе сборки попадают в бандл открытым текстом — секретам там не место.
  • Анализ размера: rollup-plugin-visualizer, source-map-explorer — найти, какая библиотека раздула бандл.
  • Транспиляция (esbuild, SWC, Babel) — синтаксис под нужные браузеры.

Критерии освоения

Junior ≈ 4 ч

  • Создаёт проект на Vite, запускает dev-сервер и собирает продакшен-версию

Практика. Создать проект на Vite с TypeScript и React и настроить переменные окружения.

Middle ≈ 6 ч

  • Анализирует состав бандла и уменьшает его разделением кода и заменой тяжёлых библиотек
  • Объясняет tree shaking, хеши в именах файлов и source maps

Практика. Уменьшить начальный бандл существующего проекта минимум на 30% и описать, за счёт чего.

Чем отличаются атрибуты async и defer у тега script?Junior

Обычный <script> останавливает разбор HTML до загрузки и выполнения. defer — загрузка параллельно, выполнение после разбора HTML, по порядку подключения. async — загрузка параллельно, выполнение сразу по готовности, в произвольном порядке.
