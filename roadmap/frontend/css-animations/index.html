Анимации и переходы

Полезно знать с Junior

transition, keyframes и производительные анимации без рывков.

.button { transition: transform 150ms ease, background-color 150ms; }
.button:hover { transform: translateY(-1px); }

@keyframes fade-in { from { opacity: 0 } to { opacity: 1 } }
.toast { animation: fade-in 200ms ease-out; }

@media (prefers-reduced-motion: reduce) {
  * { animation: none !important; transition: none !important; }
}

Что важно знать

  • Дёшево анимировать transform и opacity — они обрабатываются на этапе композиции, без пересчёта раскладки. Анимация width, top, margin вызывает layout на каждом кадре — рывки.
  • will-change — подсказка браузеру вынести элемент в отдельный слой; использовать точечно.
  • Для сложных последовательностей — Web Animations API или библиотеки (Motion).
  • Уважать настройку «уменьшить движение» у пользователя.

Критерии освоения

Junior ≈ 3 ч

  • Делает переходы и анимации на transition и keyframes

Практика. Сделать анимации появления модального окна и тоста без JavaScript.

Middle ≈ 3 ч

  • Анимирует только transform и opacity и проверяет плавность в профайлере
  • Учитывает prefers-reduced-motion

Практика. Найти анимацию, вызывающую layout на каждом кадре, переписать её на transform и сравнить профили.
