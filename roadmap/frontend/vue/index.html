Vue

Альтернатива с Junior

Прогрессивный фреймворк с шаблонами и реактивностью — альтернатива React.

Vue строит интерфейс из однофайловых компонентов (.vue): шаблон, логика и стили вместе. Реактивность на прокси: изменение ref или reactive автоматически обновляет зависимые части шаблона, без ручной мемоизации.

<script setup>
import { ref, computed } from "vue";
const n = ref(0);
const double = computed(() => n.value * 2);
</script>
<template><button @click="n++">{{ n }} × 2 = {{ double }}</button></template>

Что важно знать

  • Composition API (setup, ref, computed, watch) — современный стиль; Options API встречается в старом коде.
  • Директивы: v-if, v-for с :key, v-model, v-bind, v-on.
  • Экосистема: Pinia (состояние), Vue Router, Nuxt (SSR).
  • Идеи те же, что в React: компоненты, props вниз, события вверх, вычисляемые значения вместо дублирования состояния.

Критерии освоения

Junior ≈ 20 ч

  • Пишет однофайловые компоненты на Composition API с ref, computed и директивами
  • Передаёт данные через props и события, использует v-model

Практика. Сделать на Vue список задач с фильтрами, формой и сохранением.

Middle ≈ 16 ч

  • Управляет состоянием через Pinia и маршрутизацией через Vue Router
  • Объясняет устройство реактивности на прокси и её ограничения

Практика. Сделать на Vue и Nuxt каталог с серверным рендерингом, Pinia и маршрутами.
