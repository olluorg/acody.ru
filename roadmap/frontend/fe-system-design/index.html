Frontend system design

Основа с Senior

Проектирование интерфейса целиком — требования, компоненты, данные, производительность, доступность.

Секция frontend system design проверяет, как вы строите интерфейс целиком, а не отдельный компонент.

Структура ответа

  1. Требования: функции, устройства, объём данных, офлайн, доступность, SEO.
  2. Компоненты и их ответственность.
  3. Данные: модель, API, кэш, нормализация, пагинация, реальное время.
  4. Рендеринг: CSR, SSR, стриминг, виртуализация.
  5. Производительность: бюджеты, ленивые загрузки, Core Web Vitals.
  6. Доступность и интернационализация.
  7. Наблюдаемость и обработка ошибок.

Типовые задачи: автодополнение, лента новостей, чат, таблица на миллион строк, совместный редактор, загрузка файлов.

Критерии освоения

Senior ≈ 16 ч

  • Проводит секцию frontend system design — требования, компоненты, модель данных, API, производительность, доступность
  • Обсуждает компромиссы (рендеринг, кэш, реальное время) с оценкой последствий
  • Планирует постепенную миграцию legacy-фронтенда на новый стек

Практика. Разобрать письменно 3 задачи frontend system design (автодополнение, лента с бесконечной прокруткой, совместный редактор) по единой структуре и пройти пробное собеседование.

Вопросы с собеседований

  • Спроектируйте компонент поиска с автодополнением. Senior

    Уточнить требования (источник данных, объём, задержка, мобильные, офлайн), затем: debounce ввода (~150–300 мс), отмена устаревших запросов (AbortController) и защита от гонок…

  • Как держать производительность большого фронтенд-приложения под контролем? Senior

    Производительность деградирует незаметно — по килобайту в каждом PR. Удержать её помогают бюджеты (размер JS на маршрут, LCP, INP) с проверкой в CI, которая блокирует превышение…

  • Как постепенно переписать большое legacy-приложение на новый стек? Senior

    Переписывать всё с нуля — главный риск: годы без новых функций и вечная погоня за старой системой. Работает постепенная замена (strangler fig): новый стек встраивается в старое…
