Модули

Основа с Junior

import и export, ES-модули в браузере и в сборке, динамический импорт.

// math.js
export function sum(a, b) { return a + b; }
export default class Calculator {}

// app.js
import Calculator, { sum } from "./math.js";
const { Chart } = await import("./chart.js");   // загрузить по требованию

Что важно знать

  • ES-модули (import/export) — стандарт; CommonJS (require) — наследие Node.js, встречается в старых пакетах.
  • У модуля своя область видимости и строгий режим; код модуля выполняется один раз, при первом импорте.
  • Импорты статичны — сборщик видит граф зависимостей и выкидывает неиспользуемое (tree shaking).
  • Динамический import() возвращает промис и создаёт отдельный файл сборки — основа разделения кода по маршрутам.
  • В браузере: <script type="module"> — отложенное выполнение как у defer.
  • Именованные экспорты удобнее для рефакторинга и автодополнения, чем default.

Критерии освоения

Junior ≈ 3 ч

  • Использует import и export, именованные и по умолчанию

Практика. Разбить учебный проект на модули с явными импортами.

Middle ≈ 3 ч

  • Объясняет tree shaking и пишет модули без побочных эффектов при импорте
  • Разделяет код через динамический import

Практика. Вынести тяжёлую библиотеку в динамический импорт и измерить уменьшение начального бандла.
