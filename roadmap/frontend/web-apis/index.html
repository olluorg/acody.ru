Браузерные API

Полезно знать с Junior

Хранилища, Web Workers, Service Worker и PWA, Intersection Observer и другие возможности платформы.

Браузер умеет гораздо больше, чем показывать страницы.

APIдля чего
localStorage, sessionStorageмаленькие данные строками, синхронно
IndexedDBбольшие структурированные данные, офлайн
Cookiesмаленькие данные, уходят на сервер с каждым запросом
Web Workersвычисления в отдельном потоке
Service Workerперехват запросов, офлайн-режим, push-уведомления
Intersection Observerэлемент появился в видимой области: ленивая загрузка, бесконечная лента
ResizeObserverизменился размер элемента
History APIмаршрутизация в SPA
Clipboard, Notifications, Geolocationдоступ к возможностям устройства с разрешения пользователя

PWA — веб-приложение с манифестом и Service Worker: устанавливается на домашний экран, работает офлайн. Для многих задач заменяет отдельное мобильное приложение.

Критерии освоения

Junior ≈ 3 ч

  • Использует localStorage и sessionStorage и понимает их ограничения

Практика. Сохранять черновик формы в localStorage с обработкой ошибок доступа.

Middle ≈ 6 ч

  • Использует Intersection Observer для ленивой загрузки и бесконечной ленты
  • Выносит тяжёлые вычисления в Web Worker
  • Объясняет Service Worker и делает простое офлайн-кэширование

Практика. Сделать бесконечную ленту на Intersection Observer и офлайн-режим страницы на Service Worker.

  • Что такое cookies? Чем они отличаются от localStorage и sessionStorage? Junior

    Cookies — небольшие данные, которые браузер отправляет на сервер с каждым запросом (сессия, настройки); localStorage и sessionStorage — хранилища, доступные только скриптам…

  • Какие браузерные API полезны фронтенд-разработчику — IntersectionObserver, ResizeObserver, Storage, History? Junior

    IntersectionObserver — сообщает, когда элемент входит в видимую область: ленивая загрузка, бесконечная прокрутка, аналитика просмотров — без дорогих обработчиков scroll…
