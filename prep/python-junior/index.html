Вопросы на собеседовании Python junior

Типы данных, коллекции, функции, генераторы, ООП и конкурентность — то, о чём спрашивают начинающих Python-разработчиков почти на каждом собеседовании.

  1. Что такое *args и **kwargs? Junior

    args собирает лишние позиционные аргументы в кортеж, kwargs — лишние именованные в словарь.

  2. Как передаются аргументы в функцию — по значению или по ссылке? Junior

    Ни то ни другое в классическом смысле: передаётся ссылка на объект (call by sharing).

  3. Как работают async и await? Junior

    async def создаёт корутину, await — точка, где она отдаёт управление циклу событий, пока ждёт.

  4. Как запустить несколько корутин одновременно и получить их результаты? Junior

    Точка входа — asyncio.run(main()): создаёт цикл событий и выполняет корутину. Несколько корутин одновременно запускают asyncio.gather(a(), b(), c()) — результаты приходят в том же…

  5. Что такое self и __init__ в классе? Junior

    self — ссылка на текущий экземпляр, Python передаёт её в метод первым аргументом.

  6. Что такое замыкание? Junior

    Замыкание — вложенная функция, которая помнит переменные внешней функции после её завершения.

  7. Какая сложность у основных операций со списком, словарём и множеством? Junior

    Список — массив: доступ по индексу и append — O(1), вставка в начало и поиск in — O(n).

  8. Чем list comprehension отличается от генераторного выражения? Junior

    [...] сразу строит весь список в памяти, (...) — ленивый генератор.

  9. Что такое контекстный менеджер и как работает with? Junior

    Контекстный менеджер гарантирует подготовку и очистку вокруг блока with, даже при исключении.

  10. Чем поверхностная копия отличается от глубокой? Junior

    Поверхностная копия создаёт новый контейнер со старыми элементами, глубокая — копирует всё рекурсивно.

  11. Что такое декоратор и как его написать? Junior

    Декоратор — функция, которая принимает функцию и возвращает новую; @dec — сахар для f = dec(f).

  12. Как устроен словарь в Python? Junior

    dict — хеш-таблица: по hash(key) находится место ключа, поиск в среднем за O(1).

  13. Что такое магические методы? Чем __str__ отличается от __repr__? Junior

    Магические методы (__имя__) — крючки, через которые объект поддерживает встроенные операции языка.

  14. Как написать простой HTTP API на FastAPI? Junior

    Создать приложение app = FastAPI(), объявить обработчики декораторами @app.get, @app.post и др. Параметр из пути (/items/{item_id}) становится аргументом функции, остальные…

  15. Что такое генератор и чем он полезен? Junior

    Генератор — функция с yield: отдаёт значения по одному и замирает между ними, сохраняя состояние.

  16. Что такое GIL? Junior

    GIL — блокировка в CPython: байткод Python в один момент выполняет только один поток.

  17. Как работают наследование, super() и MRO? Junior

    MRO — порядок, в котором Python ищет метод по иерархии классов; super() вызывает следующий класс в MRO.

  18. Чем отличается is от ==? Junior

    == сравнивает значения, is — что это один и тот же объект.

  19. Чем итератор отличается от итерируемого объекта? Junior

    Итерируемый объект умеет выдать итератор (__iter__), итератор выдаёт значения по одному (__next__).

  20. Как работать с JSON в Python и что делать с датами и своими объектами? Junior

    json.dumps(obj) превращает объект в строку, json.loads(s) — строку в объект; dump/load — то же для файлов. Поддерживаются только dict, list, str, int, float, bool, None; кортеж…

  21. Чем список отличается от кортежа? Junior

    Список изменяемый, кортеж — нет; отсюда остальные различия.

  22. Почему нельзя использовать изменяемый объект как значение аргумента по умолчанию? Junior

    Значение по умолчанию вычисляется один раз — при определении функции, а не при каждом вызове.

  23. Чем изменяемые типы отличаются от неизменяемых? Junior

    Изменяемый объект меняется на месте, неизменяемый — только заменяется новым.

  24. Как подключить проверку типов mypy или pyright к проекту? Junior

    mypy и pyright — статические анализаторы: читают код и аннотации без запуска и находят несоответствия типов (передали str вместо int, забыли проверить None, вызвали несуществующий…

  25. Зачем нужна конструкция if __name__ == "__main__"? Junior

    Код под if __name__ == "__main__": выполняется, только когда файл запущен как скрипт, а не импортирован.

  26. Что такое @property и зачем он нужен? Junior

    @property превращает метод в атрибут: снаружи obj.area, внутри — вычисление или проверка.

  27. Как проверять входные данные с помощью Pydantic? Junior

    Pydantic проверяет и преобразует данные во время выполнения по аннотациям класса-наследника BaseModel: строку «42» превратит в int, а «abc» для int отклонит с понятной ошибкой…

  28. Как писать тесты на pytest — assert, запуск, параметризация? Junior

    Тест — функция с именем test_… в файле test_.py, проверки — обычный assert: pytest показывает, какие значения не совпали. Запуск — команда pytest (или pytest путь::имя_теста)…

  29. Как правильно делать HTTP-запросы из Python — requests и httpx? Junior

    requests — синхронная библиотека, httpx — похожий интерфейс плюс асинхронный клиент и HTTP/2. Обязательные привычки: всегда задавать timeout (по умолчанию requests ждёт…

  30. Как работают области видимости в Python? Junior

    Имя ищется по цепочке LEGB: Local → Enclosing → Global → Built-in.

  31. Что такое множество (set) и когда его использовать? Junior

    set — неупорядоченный набор уникальных хешируемых элементов на хеш-таблице.

  32. Как работают срезы в Python? Junior

    seq[start:stop:step] — новая последовательность с start включительно до stop не включая.

  33. Чем @staticmethod отличается от @classmethod? Junior

    @classmethod получает класс (cls), @staticmethod не получает ничего — это обычная функция внутри класса.

  34. Чем отличаются threading, multiprocessing и asyncio? Junior

    Потоки и asyncio — для ожидания ввода-вывода, процессы — для вычислений на нескольких ядрах.

  35. Как работают try, except, else и finally? Junior

    try — опасный код, except — обработка, else — если ошибки не было, finally — всегда.

  36. Что такое аннотации типов и проверяются ли они при выполнении? Junior

    Аннотации — подсказки о типах для людей и инструментов; интерпретатор их не проверяет.

  37. Как аннотировать списки, словари, необязательные значения и объединения типов? Junior

    Коллекции: list[int], dict[str, float], set[str], tuple[int, str] (фиксированный) и tuple[int, ...] (любой длины) — встроенные типы в скобках с Python 3.9. Необязательное значение…

  38. Зачем нужно виртуальное окружение и как управлять зависимостями? Junior

    Виртуальное окружение — отдельная копия Python со своими пакетами для каждого проекта.
